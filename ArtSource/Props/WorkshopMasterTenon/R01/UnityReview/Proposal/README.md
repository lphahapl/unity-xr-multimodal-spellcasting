# 双铜销压挡顶缘提案

这是新增视觉与机械构想，未获玩法或审美定稿；不是第二章原设事实。没有更改主榫，也没有声称本体存在可扣槽的承力肩。

两枚铜压挡装在座上，闭合时各覆盖主榫顶缘约 10 mm，压挡底面比主榫顶面高 2 mm。假设主榫向上抬 8 mm，真实 BoxCollider 相交量约 6 mm，说明闭合形态有实体阻挡，不只是灯光状态。

退开时每侧移动 85 mm，压挡内缘距主榫侧面约 75 mm；同样抬高 8 mm 的碰撞检查返回 0。两图机位、主榫、材质、灯光相同，只移动铜压挡。

- `01_Closed_TopEdgeStops.png`：压挡顶缘的闭合状态。
- `02_Retracted_ClearTop.png`：铜压挡退开，露出上方取物空间。

尚未实现承力结构工程分析、手型可达性、敌人/清场事件、正式 Take 锁或章节连接。支座是便于比较几何动作的独立粗样，原已通过的抓插场景、Prefab 和包未修改。
