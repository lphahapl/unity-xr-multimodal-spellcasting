# 汉白玉校准主榫 · 清圭 R03

本轮依据 R02B 的新退修意见：铜玉仍像融为一体，玉感不对。R03 A 已交独立结构/材质首样，保留 C4 轮廓、原方插端和 R02B 历史。当前为 40,024 三角、3 材质候选；可批注，未完成最终 LOD、细刻烘焙和玉感验收，未替代正式章节。

R03 分为闭合玉芯、闭合青铜包框/孔帽和 18 条独立表面圆金丝。铜帽有终止端面及内壁，玉芯有承口。原布尔孔口偏移造成的扇形尖折已重建；Unity 首拍的大块三角明暗另查明为 Mobile 阴影偏置，并限制本物投影偏置后复拍消除。两种问题没有混为法线修复。冠顶有限分段、铜尾小缺口与普通光中偏均匀的玉体仍是首样待办。

Unity 6000.3.10f1 / URP 17.3 / D3D11 按二章现行 Mobile URP 灯光与原相机参数完成同批同帧 B/R03 对照（左 B、右 R03）、11 张照片及 4 秒固定光转动。玉芯使用不透明表面、实测几何厚度和暖透近似；背景透图响应为 0，逆光有响应，真实外物可遮挡，关灯无自发光。这些是桌面技术检查，不等于软玉观感批准或实测光学常数。

原④孔的 6,056 个真实三角缓存用于四向 25 步几何装配核验，实际 153mm 孔及 106mm 插端路径无穿插；过深与 120mm 量规斜插正控制有效。实际 106mm 端斜转 45° 几何上能进入，不能说它会碰壁。R03 视觉 Prefab 尚未接抓取、SnapZone 或 XR。旧 R01/R02/B 的 Unity 保护核验为 1,310/1,310 文件不变。

结构 QA 无错误；本次首样接受两类告警并保留后续优化：玉芯 11、铜框 2 个 10μm 范围近邻点不直接合并，以免破坏当前闭合收口；2 对隐藏背向接触面用于保持两件各自闭合，最终 LOD 再评估隐面成本。GLB 的 4 对拆点公共边提示经精确投影确认重叠面积为 0；只在诊断副本恢复相同坐标邻接后复查，交付 GLB 未被改写。玉/铜/金分别为 11,196 / 21,328 / 7,500 三角。
