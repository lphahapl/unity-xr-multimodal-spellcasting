- [快速连播](rapid.wav)：同一顺序连续三轮，间隔 0.4 秒，18 次，约 7.4 秒。

## 响度和结构依据

用律印前 400 ms 的 K 加权能量作为对齐基准，新五音误差均约 −0.0003 dB。该指标只让比较在相近测量响度下进行，不能证明不同材质在所有设备上主观等响，也不声称集成 LUFS。Prefab 音量统一沿用 0.62。源音峰值依次为规 −6.10、矩 −2.57、准 −2.83、绳 −2.58、衡 −2.64 dBFS；均为 48 kHz、单声道、PCM16，首尾归零，没有削波。

矩的第二击能量比第一击高约 3.38 dB；其他新音各有一个主要起音。规以宽带摩擦为主，绳改用短拨弦延迟环，准是短促落点；衡约 92.8% 的频谱能量落在 350–1800 Hz，保留小扬声器能呈现的实体线索。比较与快速连播文件均使用统一 0 dB 总增益，读盘峰值 −2.57 dBFS，没有用逐印音量差来制造区分。

以上说明可核验的发声结构变化，**不是真人盲听通过的结论**。父代理与执行代理只完成文件、波形及运行证据检查；本轮还需用户实际试听评价材质感和可辨性。未测试 Quest 实机扬声器或耳机。
