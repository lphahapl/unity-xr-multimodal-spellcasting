| 印 | 特点 | 本次具体调整 |
|---|---|---|
| 规 | 围合守界 | 开头摩擦退后，动作回拢后以短木接触收口，重点移到末端 |
| 矩 | 转折成形 | 主木靠合层加强并提前，保留短促明确的转角音头，掌面轻衬 |
| 律 | 起律激发 | 保留原铜鸣文件，不作为其他印的响度上限 |
| 准 | 校齐稳定 | 减少和缩短底擦，轻点稳住；避免持续摩擦掩盖定点 |
| 绳 | 联结约束 | 原始抽拉延至约290毫秒，形成持续牵引，再自然收束 |
| 衡 | 承重镇定 | 木体承托加强、掌面先承接，中频木体接续并自然阻尼收尾 |

柔和通过音头、材质和收尾实现，力度按动作需要分配。没有统一峰值、RMS或K加权能量目标；相对律印的测量仅用于描述。当前衡印峰值约−3.58dBFS，律印约−3.83dBFS，这只说明瞬时峰值关系，不表示衡的整体听感已更响。矩与衡的主体更明确，准保留轻稳，绳保留持续感；仍需实际听感批注。

## 来源、复现和边界

来源仍是项目既有Battle Sound Library作者拟音，具体原文件、SHA、裁剪范围、增益、淡化见[source_recipe.json](source_recipe.json)。本次没有新增外部素材或合成主体；动作含义是设计解释，不声称本人录制了真实圆规、纸、绳或秤。来源与游戏使用范围沿用[V3来源记录](../SealConfirmationV3/README.md#原件出处与使用边界)及[核查文件](../../../Logs/t01-seal-audio-v3-20261125/source-policy.json)。原始库只读，不作为可自由分发采样库。

```powershell
python -X utf8 ArtSource/Audio/SealConfirmationV3_1/render_v3_1.py
```

脚本只写本目录与专属Logs/audio，默认不替换主工程。所有改动均有[逐层旧新对照](layer_changes_from_v3.json)，可复现本版；V3音频和配方保留。[QA](qa.json)记录48kHz单声道PCM16、0.35–0.54秒、端点/尾部、峰值、4倍采样真峰估算、频带和20/100/400毫秒能量趋势。五音无削波，真峰估算约−11.63至−3.58dBTP；该估算不是认证测量仪。旧版相对律印的目标字段不再作为本版验收条件。

Unity6000.3.10f1/D3D11独占副本执行原matcher→ForwardSeal→PlaySealConfirmation→SealGlyphPulse，原音量0.62、空间混合0.85。规矩律衡稳定保持一次、有效退出后重结第二次；准绳零识别事件、只直接模板预览。混合12次包含8次matcher确认与4次直接预览，最多3源重叠，全部自然播完，实际混音峰0.304679、零削波。按逐印实际PCM峰选出的衡印另连续12次，12次真实matcher确认、最多2源重叠、全部自然停止，峰0.3021544、零削波。原生进程退出码0。[结果](../../../Logs/t01-seal-audio-v3_1-20261125/unity/result.txt) · [命令与退出](../../../Logs/t01-seal-audio-v3_1-20261125/unity/process-exit.json)。
