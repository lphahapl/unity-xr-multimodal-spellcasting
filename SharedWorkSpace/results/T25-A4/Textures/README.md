# T25-A4 镇石材质

石、铜各有一组 2048 × 2048 的可平铺 PNG。朱印使用模型方单独制作的印面 UV 和遮罩。可先对照两张 Cycles 实材质近照检查光照与 UV 比例。[石材样块](Previews/Stone_Closeup.png) · [弯铜带样块](Previews/Bronze_Closeup.png)

| 材质 | 物理比例与 UV | 表面信息 |
|---|---|---|
| [Stone](Stone) | 1.0 米重复一张。U 沿石材层理 | 细片理与少量浅色矿物充填、分叉裂口、敲凿留下的细长断面。旧切口较暗、积尘，较新的断面略浅，局部矿片反光较细。石材金属度为零 |
| [Bronze](Bronze) | 0.5 米重复一张。V 沿铜带长度，U 横过带宽 | 长向打磨丝、成组划痕和压坑切入氧化皮。裸铜粗糙度较低，褐色氧化与薄绿锈处更粗，金属分量更低。强度过半的绿锈占整张约 4.9% |

| 文件后缀 | 解读 |
|---|---|
| `BaseColor` | sRGB 颜色，贴图内没有灯光和镜面高光 |
| `NormalGL` | 切线空间 OpenGL +Y，作为 Non-Color 采样。样张中 Blender Normal Map 强度分别为石 0.85、铜 0.65 |
| `Roughness` / `Metallic` | 线性灰度。可直接接对应材质输入 |
| `ORM` | 线性 RGB。R 为局部遮蔽、**G 为粗糙度**、B 为金属度。G/B 和两张独立灰度图逐像素一致。使用光滑度输入时取 `1 − Roughness`，再按所用 Shader 的通道布局打包 |

若要在铜带边缘增加磨亮，使用模型自身的凸棱、接触面顶点色或烘焙遮罩，窄范围提高金属度并降低粗糙度。裸露石角可沿实际崩口浅提色，保留石面矿理。凹槽和填朱笔画仍用模型的独立遮罩。

取完整邻接边界与图内同向相邻像素的平均绝对差作比值，十张图中最大为石 1.421、铜 1.221。解码法线最大长度误差低于 0.006。独立通道、图幅、哈希及双向接缝数据已记录。渲染使用分别标定的石样和弯带样块，整件镇石上的 UV、边缘磨损与朱印由建模方联验。[数值与哈希](Source/map-checks.json) · [材质分布](Source/material-stats.json)
