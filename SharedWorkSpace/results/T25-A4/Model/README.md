# T-25 A4 镇石

以生产 `BallastStone` 刚体中心为原点，米制。顶面四角组成一枚大方印，两道有实际厚度的铜带沿四侧闭合，交叠处上带抬高，底部收进倒角铜托。正面可由小朱记和双铆钉接头辨认。

**实际包围盒**（Unity X、Y、Z）为 1.01160 × 1.04700 × 1.02080 m，最小点 (−0.50580, −0.52500, −0.50580)，最大点 (+0.50580, +0.52200, +0.51500)。底托在 Y=−0.525 处的共面支承面积为 0.39407 m²。三维顶点均在现有 1.05 m 方盒内。中心可直接对物理石根，+Y 朝上，+Z 面有小朱记。

OBJ 坐标和 GLB 解码坐标同取 (Blender X, Blender Z, −Blender Y)，OBJ 使用有显式外法线的标准逆时针面顺序。若编程写入 Unity Mesh，请按该引擎的单面绘制顺序转换。几何共 8 个封闭件、21,456 个三角形、三个材质。顶印直接刻入石面 5 mm，前小印刻入 3 mm，槽底使用填朱材质。铜带 UV 的 V 沿带长、U 横跨带宽，每 0.5 m 重复；石的 U 顺层理，每米重复。[贴图与通道说明](../Textures/README.md)

**模型验收。** Blender 5.2.2 的 game 检查通过，未报闪面、游离零件、零面积面或非流形边。保留的提醒来自重复使用的平铺 UV、两道可拆铜带内侧与石面的贴合，以及以刚体中心作原点后底面在 −0.525 m。随机分件图和线框图另存于 QA 目录。[检查记录](QA/qa.json) · [分件图](QA/review-random_three_quarter.png) · [线框图](QA/review-wire_three_quarter.png)

在空 Blender 会话中分别重新导入 FBX 和 GLB。两份均恢复 8 个网格、21,456 个三角形、三个材质和全部 UV；首尾双向最近顶点误差分别小于 0.015 mm 和 0.018 mm（比较精度为 0.01 mm）。GLB 中石与铜的 6 张 2048² PBR 图和一张 512² 朱砂颜色图都已内嵌，解码后与供图 RGB 像素逐个相同。[FBX 回读](QA/fbx-roundtrip.json) · [GLB 回读](QA/glb-roundtrip.json) · [尺寸、各部件面数和哈希](mesh-metrics.json)

该目录归档已通过的 A4 造型与制作源。动画持姿、正式 Unity 导入材质和篮槽运行结果由各自的实测记录说明。
