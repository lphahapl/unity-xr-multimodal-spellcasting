# 验收标准：纯正交无透视畸变、纯纯单色中性灰背景(#808080)、零文字、零标注、零水印、零外物

===== 全局共享形体与材质约束 (Shared Structural Anchors) =====
1. 骨骼与尺寸基准：骨架以本项目选用Meta/OpenXR SDK模板映射为准；标准26个手部关节点不规定统一毫米手长。本项目绘图参照为手长185mm（腕横纹至最长中指尖）、掌宽82mm、挂载处前臂宽约68-70mm，尚未从本地SDK FBX实测。可见前臂腕后150mm为本项目方案，平滑麻布收口；前臂/IK驱动仍须验证，不能仅凭截断长度保证无扭曲。
2. 角色身份与肌理：成年男性先秦工官/勘律使双手，自然健康工匠肤色，指甲平整自然，肌腱与骨骼体积严谨扎实，轻微常年制器劳作质感，绝非机械仿生手、非日式忍者护手、非赛博义体。
3. 包覆与绑带：深黛（深炭灰/靛青黑）粗织麻布紧密交叠绑在前臂与手背外缘，贴合肌肉轮廓，完全平顺收束；严禁飘带、悬垂绳结、绑带虚浮或宽松袖口。
4. 指环细节：仅同一左手与右手的拇指、食指末节（指尖裸露）佩戴一枚窄薄哑光冷铸青铜“规矩指环”，表面阴刻浅细云雷纹，绝不跨越指骨关节；其余指节紧密包裹或自然活动，严禁额外佩戴多余首饰。
5. 准望匣挂载示意：左前臂尺骨背侧仅以极淡的细虚线轮廓示意准望匣挂载区（距腕横纹严格保留 25mm 净空），严禁在图中渲染实体青铜重盒，确保手部与前臂 3D 轮廓 100% 清晰可见无遮挡。
6. 渲染与背景：标准游戏 3D 资产建模多角度参考图（Turnaround Model Sheet），柔和中性漫射工作室布光。纯单色中性中度灰背景（#808080），完全平整无渐变、无投影、无地面、无阴影。
7. 绝对负面提示（STRICT NEGATIVE）：严禁任何中英文字、严禁标签/标注/引线/箭头/尺寸数字、严禁水印/LOGO、严禁多余漂浮物体、严禁背景阴影、严禁多指或少指畸变（每只手必须且仅有五指）。
