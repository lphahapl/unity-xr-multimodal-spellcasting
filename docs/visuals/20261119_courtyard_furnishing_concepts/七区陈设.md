# 山间校院 · 七区陈设

用户先为院落与天仪阁选了 B，再按苏醒室、试炼间、西坊、东坊、校器工坊的顺序选了 A、A、B、B、B。七处沿用现有玩家路线。天仪阁用于校准测环，柜里收弧尺，案旁备分规、砝码与油灯。星图尚未纳入世界设定。

[七区定稿总图](七区陈设定稿.jpg) · [正式美术资产表「七区陈设」](../../美术需求/首章场景美术资产需求与缺口审查.xlsx)

| 东坊 B | [门口望规尺案](05B_东坊_规尺比长.png) | 长短规尺横放，主案上打开蓝衬长匣，露出铜包头基准尺。 | [横尺架、尺匣、木托](定稿细化/05_东坊B.png) |

| 天仪阁 B | [穿堂望后门](07B_天仪阁_校准器具柜.png) | 右侧浅柜陈放铜弧尺；左长案铺布，保留绕过仪座前往崖端石门的通行空间。 | [侧墙弧尺柜、挂式分规与左案](定稿细化/07_天仪阁B.png) |
