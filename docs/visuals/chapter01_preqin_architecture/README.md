[屋顶与亭廊 R2 选稿](屋顶与亭廊_R2/README.md)收录玩家提出调整后的两版概念与先秦参考。

用户在查看[山间校院 A1](山间校院_A1.png)后确认“可以，注意材质和质感，要检查”，并要求用远端调试 Chrome 让 Gemini 对照概念图审模型。场景入口为[苏醒章](../../../Assets/Scene/Chapter01_Awakening.unity)与[山间校院](../../../Assets/Scene/Chapter01_Courtyard.unity)。

## 正式建筑与复用

| 元素 | 生产方式及落点 | Unity 回读 |
|---|---|---|
| 校器三坊与原章三段屋盖 | 依据原门窗与通路在 Blender 改造 6 套工官建筑，烘入原共用图集。西坊侧墙收紧，三座工坊保留各自入口。 | 18 份网格；含三台既有工作台，全近级 17,995 三角面。 |
| 主殿、低翼、独立院门 | 原位改造正式 FBX。顺坡排瓦，椽端单独取样年轮与干裂。 | 主殿近中远为 11,600 / 4,208 / 920 三角面。 |
| 主殿正脊双端 | [混元订单与高模](../../../ArtSource/Environment/Opening/PreqinRidgeCap/order.json)生成拱面，Blender 重建带壁厚套口与外端封口。两端共用[同一 Prefab](../../../Assets/Art/Environment/Opening/PreqinRidgeCap/PreqinRidgeCap.prefab)，按原屋脊截面装配。 | 单件 1,452 / 608 / 220 面。 |
| 天仪阁 | 重建瓦口、椽头、柱头承托与斜撑。底墙上部为带法线的暖土色，下部为粗石。 | 单阁 12,716 / 5,492 / 1,836 面，沿用 4 个材质槽。 |
| 模块回廊与校规庭单坡廊 | 直段和拐角复用原接缝与碰撞。另将校规庭单坡廊的整块木顶换成板底、圆椽、板瓦、筒瓦和压顶，并保留原框架。 | B02 直段 1,988 / 956 / 336，转角 2,436 / 1,092 / 444。单坡廊去掉 12 面旧顶，新增 3,312 面。 |
| 门闸、嵌线、台沿与石栏 | 门闸做竖板和带钉铜箍，细嵌线、框标保留用途。崖径 20 个栏段沿用原轮廓，重新展开米制石纹。 | 苏醒场景 17 个、庭院 10 个原本可见的 Cube 已全部替换。 |

## 验收与复审

Unity 6000.3.10f1 隔离工程用发布文件重开了两份场景，逐项读回全部启用的 MeshRenderer，均有网格、材质与着色器。两份场景原来 348、633 个碰撞体的开关、触发标记与包围盒一致；从量水道到天仪阁的六处地面射线能命中步道或石坪。重新烘焙了三张水面反射立方体贴图。[Unity 回读与 LOD 数值](Unity回读.txt) · [按文件的资产清单和哈希](制作用件与文件清单.tsv)

Gemini 网页接受了定稿图、近档 GLB 压缩包、实际脊端的完整顶点／UV／三角形 JSON、材质参数、同机位截图及真实模型转台。它能读 JSON 和视频帧，压缩包中只识别到文件清单。第一轮提出瓦排重复、椽头端纹不清和阁基缺少法线。复审按金属光泽遮罩的实际 Alpha 纠正了对粗糙度乘数的误读，并确认修订后的屋面、椽端和脊端装配。补拍侧墙后，确认西坊侧窗开敞率从约 89% 降到 58%，正门采样仍畅通。天仪阁近看时椽端仍有轻微低模折角。头显帧时与双目运动表现尚待设备测量。[Gemini 复审会话](https://gemini.google.com/app/ea1a4dd0be23bc26) · [三轮文字反馈](Gemini审查记录.json)
