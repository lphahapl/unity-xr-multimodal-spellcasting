## 截图中的问题

- 主殿的大直坡占据画面，配楼也用了类似的直坡和瓦色。优先靠檐高、脊高和坡度转折区分主次。低翼保留原有开门、抬头净空，先调整屋面进深和正脊标高。
- L 形回廊从上方看有暗三角，两条檐线在转角没有清楚的交接。连檐版让屋脊同标高并收出内角斜沟。转角亭版将两条廊顶分别搭入亭檐下方。
- 瓦垄色差按烧制批次、坡向和雨痕分布。瓦口适度保留断面和搭接阴影，梁枋和椽头在檐下读作一套承托。柱距与柱础要给 VR 走位留出净宽。

## 调研

- **院落与台基**。凤雏一号展示前堂后室及庭院关系，遗址的现存证据是夯土地基。主殿与低翼在图里按院落层级组织，屋顶细部由游戏设计。 [北京大学周原虚拟考古导览](https://cate.pku.edu.cn/info/1013/1050.htm)
- **开敞亭面**。浙博的春秋伎乐铜屋实物显示敞开的南面、透空侧壁、圆明柱和四角攒尖顶。转角亭借用开敞正面与清楚的四坡体量，天仪阁的顶部采光、短檐与承托按照场景用途设计。 [浙江省博物馆藏品页及照片](https://www.zjmuseum.com.cn/topic/ywsd/collection1-1-2.html)
- **灰陶瓦口**。秦雍城的春秋晚期或战国早期制陶作坊有筒瓦、瓦当及制陶工序资料。北京市文物局公布的战国饕餮纹半瓦当照片可比对断面，实物半径 9.5 厘米。图中灰陶化繁为简，借实物的厚度和色阶。 [陕西历史博物馆秦雍城资料](https://www.sxhm.com/info/news/detail/13321.html) · [北京市文物局实物图](https://wwj.beijing.gov.cn/bjww/362760/10818711/10858084/index.html)

## 两张选稿

- **A｜连檐回廊**。主殿保留四坡，压低坡高并在近檐处放缓。低翼用简单双坡。回廊两段屋面从同一高度转弯，内角斜沟在瓦面可读。[A 原图](A_连檐回廊.png)
- **B2｜转角小亭**。主殿由带木格的山花和下段四坡打断大直坡。回廊转角用略高、四面通风的小亭压住两侧廊顶，院里走近时有一个清楚的转弯点。天仪阁前排改为粗圆木柱，窗格退到两侧，采光口边沿压低并收进四坡屋面的轮廓。[B2 原图](B2_转角小亭.png)

如采用 B2，转角台沿按通行面齐平处理，内侧柱脚和斜撑需要通过眼高视角、净空与两向转身检查。当前概念比例供选稿，尺寸以场内量测为准。


## R2 正式模型与瓦样

- **主殿**。两端改为三角木格山花，下方屋坡连续接到檐口，原陶收头重新安装于加长的正脊。三档 11,600 / 4,208 / 920 三角面。[主殿 Prefab](../../../../Assets/Art/Environment/Opening/CourtArchitecture/CourtMainRoof/CourtMainRoof.prefab) · [Blender 源文件](../../../../ArtSource/Environment/Opening/CourtArchitecture/R2_MainRoof/CourtMainRoof_B2.blend)
- **天仪阁**。加宽低檐轮廓，微挑四角，保留侧格栅、穿堂和顶部木框采光口。三档 12,684 / 5,180 / 1,732 三角面。[天仪阁 Prefab](../../../../Assets/Art/Environment/Opening/TianyiPavilionKit/TianyiPavilion.prefab) · [Blender 源文件](../../../../ArtSource/Environment/Opening/TianyiPavilionKit/TianyiPavilion.blend)
- **转角亭**。原 L 形位置抬起独立四坡亭顶，两段低廊伸进去。根据用户指出的瓦形差异，Blender 为近档增加有厚度的成排筒瓦和两道实体搭接，修正旧遮蔽图出现的深色横带。三档 8,012 / 1,052 / 450 三角面，近档相对未加筒瓦的 R2 样件增加 5,520 面，场景只有一处该转角。[转角亭 Prefab](../../../../Assets/Art/Environment/Opening/CourtyardInfill/B02/GalleryCorner.prefab) · [Blender 源文件](../../../../ArtSource/Environment/Opening/CourtyardInfill/B02_R2_Pavilion.blend)
- **混元试样**。Chrome 远程调试恢复后，混元 V3.1 50k 档生成了一件两段搭接的瓦样。回件瓦背封平、板瓦和筒瓦连体，陶色偏浅。已把取样得到的筒瓦截面和约 17 毫米搭阶用于 8,012 面的转角亭近档，在同机位试装。试装文件和回件留在美术源目录，Unity 当前默认使用已发布的 R2。Gemini 收到真实瓦背照及焊合统计并返回了补充答复。[混元输入图](混元输入_灰陶搭瓦.png)
