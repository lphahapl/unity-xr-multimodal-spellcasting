# 断衡悬道群山样件

[打开 Unity 山谷预览场景](../../../Assets/Scene/Chapter02_SuspendedPath_MountainPreview.unity) · [四个同机位的原版／样件对照](unity-comparison.jpg) · [高程与侵蚀差值](height-data.png)

山谷基于金沙江虎跳峡一带两块 Copernicus GLO-30 高程数据，按场景尺度旋转、缩放和裁切。离线四邻域迭代给已有沟谷增加冲刷与沉积，平均绝对改动 2.25 m。关卡核心从石门到谷底仍沿用人工制作的桥、平台和绝壁。高程网格在其下方让出空间，到关卡外围逐级降低网格密度，同一地貌继续烘成全景山际线。[数据、参数与重建](../../../ArtSource/Environment/SuspendedPath/MountainTerrain/README.md) · [算法来源与分层依据](../../research/CHAPTER02_MOUNTAIN_TERRAIN_20261123_ZH.md)

| 层 | 预览配置 |
| --- | --- |
| 关卡核心 | +80、0、−80 m 仍使用既有平台、桥和碰撞。四周高程网格穿过核心下方，向外接真实山坡。 |
| 三维山坡 | 1.22 × 1.22 km，35,912 三角面，1 个地形渲染器。近密远疏，无附加碰撞或投影。 |
| 远景 | 4096 × 2048 经纬全景，Android 导入上限 2048，纹理压缩 ASTC 6×6。全景层固定方位，山体边缘用雾过渡。 |

## 验证与状态

从石门旁高处、中控、谷底和山谷斜上方拍四组桌面同机位图，分别观察地形层次、工作区背山、立壁遮挡与远山接合。Unity 6000.3.10f1 的独立工程回读网格尺寸、数量、UV 和四角朝向，对照五个脚下射线的碰撞体和命中高程。Blender 重新导入 FBX，检查了外边界、法线和退化面。[Unity 读回记录](UnityReadback.txt)

预览场景作为第二章地形候选交付。样件的雾和群山高度为初版美术选择。原章节仍作为对照，正式启用前待在 Quest/PICO 从 +80 m 到 −80 m 实测上下行程的双眼视差、雾带接缝和帧时。
