# 线性 RPG 测试场景使用说明

更新：2026-10-30。当前是固定流程的单人战斗试炼，不是完整剧情 RPG。自动检查结果以 `Logs/linear-rpg/` 中带时间的 JSON 为准；头显实测另行记录。

## 打开与运行

1. 保存当前场景，等 Unity 编译完成。
2. 选择 **Tools → NarutoVR → 线性RPG → 创建或打开测试场景**。目标是 `Assets/SealCombat/Scenes/LinearRpgTest.unity`。构建器首次复制庭院并创建独立配置，之后只打开，不覆盖你调过的场景或资产。
3. 按既有 Quest → Steam Link → SteamVR OpenXR 路径连接，进入 Play。当前语音在电脑运行，尚未打通 Android 一体机语音。
4. 头显中保留左侧结印/语音诊断，庭院右侧增加中文角色与关卡面板。电脑 Game 窗口右侧有可滚动的模拟按钮。

不戴头显也可检查关卡、资源和物理移动，但电脑按钮生成火球仍要求有效手部追踪；正式代码不会用假手姿补足追踪。自动化验收会显式注入测试手姿，并在报告中标注。

## 三个固定阶段

| 阶段 | 目标 | 通关奖励 |
|---|---|---|
| 火球基础 | 三个60生命训练靶；初始仅解锁火球 | 40货币，解锁子印护盾与护体咒 |
| 护盾与闪避 | 三个90生命训练靶；开启范围攻击预警 | 40货币 |
| 综合试炼 | 三个120生命训练靶；持续练习施法和位移 | 60货币，完成试炼 |

击破全部靶，默认等待3秒自动推进。推进时验证下一检查点可落地，重置下一阶段靶子，恢复HP/MP，清理上一阶段临时效果并保存。技能CD继续保留。没有刷怪AI或复杂任务系统。

第二阶段起，攻击训练器约每6秒锁定当时站位，红圈预警1.5秒后结算半径0.65米内的25点伤害。离开圈或用护盾承受。它是验证闪避/伤害链的训练装置，不能视为敌人AI。

## 操作 A

- **导航**：左手抬起、只伸直食指，其他三指收拢，稳定约0.2秒。以准备时位置为中点，轻移约5厘米选择前后左右，驻留约0.35秒确认。每次成功后回中才能再次选择。放下左手退出。
- **闪避**：导航准备期间，右手张掌向方向短划。默认有效位移约10厘米、时长0.06～0.45秒，闪避0.8米，冷却1.2秒。检查地面、身体空间和沿途碰撞；无无敌帧。可停在节点外，不自动吸回。
- **火球**：寅印＋完整口令“火球术”，先后不限，沿用8秒组合窗。成功时右手持球；准备后前推发射。持球时前推始终归发射，包括尚未就绪时；同一推不能追加前闪。导航期间仍允许发射已有火球，张掌侧/后闪保留持球。
- **护盾**：解锁后，子印或“护体咒”立即加持。两种配方共享护盾冷却。
- **取消**：双腕都可靠追踪，低于头部约0.55米，保持0.4秒。或说“取消施法”、按Esc、点电脑取消按钮。只清待施法输入和未发射火球；护盾与飞行火球保留，已付MP/CD不退。

导航时不接受新的结印/咒语技能输入，进入/退出导航、位移、取消和恢复检查点会隔离旧证据。放下左手退出导航后重新结印/吟唱。失去追踪不算放下双手。上述角度和时间是初值，仍需真机调参。

## 角色、购买与存档

- 初始100 HP / 100 MP。成功消耗后等2秒，以每秒5 MP恢复。火球20 MP，普通盾15 MP；失败不收费。
- 电脑按钮可用60货币购买“金刚护体”（150护盾、25 MP、8秒CD）；先完成第一阶段。火球每次升级30货币，每级增加基础伤害的10%，最多3级。
- 当前购买、升级、死亡恢复是**电脑调试按钮**，头显内交互式商店/恢复菜单尚未制作。手势和正常战斗流程可以在头显里测试。
- 默认存档在 `Application.persistentDataPath/linear-rpg-v1.json`。完整实际路径可在调试器的 `SavePath` 属性或测试报告查看。保存有版本、技能白名单和备份；发现不兼容档案时不会静默覆盖。
- 检查点保存阶段、货币、解锁、升级、HP/MP和技能剩余CD。恢复到该阶段固定节点，重置训练靶；不恢复护盾、飞行物、手持球、语音/骨骼证据。死亡不自动清CD；从检查点恢复其保存的CD。
- 自动检查用独立 `linear-rpg-probe-<GUID>.json`，不会覆盖正式角色档案。测试报告和测试存档保留供排查。

## 修改配置

配置集中在 `Assets/SealCombat/Configuration/LinearRpg/`，原训练场目录独立保留。

| 修改内容 | 入口 |
|---|---|
| HP/MP上限、回蓝和等待 | `RpgPlayerDefinition` 玩家定义资产 |
| 技能消耗、CD组、口令与印 | RPG目录中的 `SkillDefinition` |
| 火球伤害、准备/轻推参数、视觉 | RPG火球效果资产 `ProjectileEffectDefinition` |
| 护盾容量和视觉 | RPG护盾效果资产 `ShieldEffectDefinition` |
| 阶段顺序、靶血量、奖励和解锁 | `RpgStageDefinition` 资产，按控制器 `stages` 顺序配置 |
| 选点、闪避、碰撞层与判定 | 场景 `RpgLocomotionController`，所有字段有中文解释 |
| 低手高度、手指角度、商店测试价格 | 场景 `LinearRpgController` |
| 攻击间隔、圈大小和伤害 | 场景 `RpgTrainingHazard` |

加阶段时也要在主控增加对应检查点；检查点ID保持稳定。运行时升级作用于克隆效果，退出Play不会把升级数值写回SO。当前商店只提供火球升级和一种隐藏盾，其他法术的购买/升级规则仍需扩充，不是通用经济系统。

## 中文语音与检查

新目录的独立词表包括“金刚护体”。启动本机服务时显式传配置，旧词表不被自动覆盖：

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\SkillVoice\Start.ps1 -Config .\Assets\SealCombat\Configuration\LinearRpg\skill-voice-config.json
```

先停止已有语音服务，避免端口占用。具体麦克风、依赖和原始录音验收见[语音设置](SKILL_VOICE_SETUP_ZH.md)。新增口令仅核对词表格式，不代表真实音频召回率已验证。

菜单 **创建场景并运行编辑器检查** 检查数值、存档、手势状态和碰撞。**运行独立存档播放检查** 会实际进入Play，模拟施法/伤害/移动，结束后自动退出。其结果不代替真机动作、追踪遮挡和舒适性测试。

完整策划及暂缓项见[线性RPG设计](LINEAR_RPG_DESIGN_ZH.md)。画符、多印序列、属性克制、硬直、完整剧情与商店、PICO真机和多人都不在本次完成范围。
