## 裁决顺序

1. 腕饰靠近或卡片悬停只高亮，不清印、不丢待处理口令、不打断导航。真正点按打开主菜单、按钮按下或拖动才占用；放腕关闭主菜单，保留的子卡本身不占用。已持球的手优先。
2. 遭遇开始进入战斗，结束进入探索；攻击预警开关与遭遇状态独立。切换时清理候选、行走和滑退进度；若食指仍伸直，先等收指，再接受新模式的移动。无有效追踪不能算收指。
3. 已持球、武器占手、结印或 UI 实际占用时不能启动闪避。扔球那次前推不能同时触发滑退。发射后可通过回胸重新准备，或等保护计时结束后重新准备；两种情况均须观察到一次**新的**明显向前动作，不能用仍伸着的手或投掷留下的速度直接后撤。保护时长与普通闪避冷却分别可调。

## 两个移动模式

| 状态 | 移动 | 闪避 |
| --- | --- | --- |
| 战斗 | 左手伸食指启用选点；先排除超距、不可达、占位和被墙挡住的节点。视线中心附近的节点可直接入围，不能继续用旧手指 0.35 米硬门槛。初始评分 60% 头显朝向、30% 手指微调、10% 距离；明显偏离两种方向时无候选。保留同目标驻留、切换迟滞、路径与落点提示，确认后传送。 | 空手右手从胸前快速向前滑动，沿起手时头显水平前向的反方向平滑移动。首测 0.8 米／0.25 秒，逐步检查地面、占位与沿途碰撞；背靠墙提前停，不自动改成侧闪。 |
| 探索 | 左食指持续伸直，沿实时头显水平视线移动；收指、放腕、丢追踪或开始 UI 操作立即停。不使用节点驻留或传送。移动追踪原点，不移动相机本地坐标。 | 不采纳闪避动作。 |

头向来自 XR 头显姿态，不依赖眼动或厂商专用裸陀螺仪。前进始终投影到地面；接近垂直时不从近零水平向量推断方向。默认抬头、低头不影响速度。可选俯仰减速：设起始角、最大减速角与最低速度倍率，平滑过渡；只影响探索行走，不改变战斗闪避距离。以上权重、速度、距离和手势阈值是首测参数，不是设备精度结论。

## Inspector、Debug 与验收

- Inspector 中文分组：战斗视线／手指／距离权重、候选角及驻留；探索步速与可选俯仰减速；右手起手区、快推距离／速度、滑退时长／距离、闪避冷却、火球发射后保护计时。
- Debug 显示当前模式、前列候选各项分与总分、驻留进度；无候选区分角度、距离、楼层、占位、遮挡。闪避显示持球、发射保护剩余时间、缺新动作、追踪失效、非战斗或路径被挡。腕部区分靠近／悬停／确认／拖动；记录变化原因，避免逐帧刷日志。
- 回归：结印时右指接近左腕仍可收词；确认操作才拦截。视线正对节点、手指略偏仍可选；隔墙不可传送。探索收指即停，模式切换不继承旧食指。侧甩火球不连带滑退；回胸或保护期结束后新快推可滑退；探索同动作无效，背靠墙不穿墙。
- 真机验收另测：同一靶侧甩、双节点消歧、上下看时是否误加减速、滑退舒适度。编辑模式与合成 Play 测试不能替代佩戴体验。

## 如何复测

电脑 Game 窗口展开「模拟操作与关卡测试」，用「进入探索／进入战斗」切换，不用改攻击预警。正式阶段由「阶段开始进入战斗移动」决定起始模式；清完目标退出战斗。移动控制器上的探索步速默认 0.95 米／秒，发射后闪避恢复默认 0.65 秒。测试时先看「移动输入与选点」里的模式、分数和拦截原因，再调参数。可选俯仰减速默认从 35° 开始，70° 时降至 55%。
