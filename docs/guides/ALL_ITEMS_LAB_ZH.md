# 随身道具联合试验场

打开 [AllItemsLab.unity](../../Assets/Samples/ToolBeltItems/AllItemsLab.unity) 后直接进入 Play。场景使用独立的 `all-items-lab.json`，每次进入从新局开始。开场有一支墨规笔和一袋四块干粮。出生点正前方是五个石台，说明牌同步显示当前气血、度力和袋内数量。

进入后使用探索移动。默认抬起左手，把食指水平指向想走的方向，收拢其余手指；转动食指即可转向，张手停步。右手拿着干粮袋时，空闲的左手仍可指向行走。如果以前在腕匣选过「选点自动行走」或「选点传送」，左食指指向空旷地面，稍停到落点环填满。双手捏着袋和饼时，先在嘴外松开左手让饼归包，再伸左食指行走。

本场远取范围为 5 米，可在玩家 Inspector 调整。退到离定律铜橛约四米半的位置，食指对准铜橛实体，看到标记再捏合。手和头部到物体都要在射程内，中间需要有无遮挡的视线。

空手靠近实物捏合，或先伸食指指向道具，看见金线和末端圆环后再捏合。左右手均可。桌面侧样板的 F8/F9 快捷键属于各自的单项场景；本场用真实玩家输入。

| 位置 | 怎么测 | 看什么 |
|---|---|---|
| 腰侧笔套 · 墨规笔 | 取笔，抬起到面前呼出自由画板。在身体附近松手，再取一次，朝身前伸直手臂松开。 | 第一次回原笔套，第二次掉地；指向地上的笔应能远取，真实笔锋还能用于画符。本场没有二章两岸的剧情标记。 |
| 腰带中央软袋 · 干粮 | 一手握袋待袋口展开，用另一只空手捏最上面的饼，保持捏合送到嘴前并停留。立刻拿开再吃下一块。也试取出一块、在嘴外松手。 | 开场气血 20，每吃一块回复 15。四块吃完到 80，袋里剩 0；嘴外松手的饼回包，气血不变。拿整袋近身松手回原口，向前伸直手臂松手才丢包。 |
| 左一 · 醒神松墨锭 | 一手拿锭，另一只手捏盖沿锭身推开，先松手，再捏最外侧墨段沿刻线侧掰。 | 两段墨逐段折下。现用交互灰盒，折段默认仅改变实物状态，正式回度力时机待定。 |
| 左二 · 冷铸青铜拓片 | 取薄片，转到合适方向，靠近能容纳它的空槽放手。再次取出后试近身松手。 | 第一次明确入槽后该口成为原槽；从台上第一次拿起时没有归槽历史。现用薄板灰盒，可验收取放和尺寸。 |
| 中间 · 定律铜橛 | 竖握铜橛，锥尖贴近地板后松手，站在纱屏内向外施放火球；也可从外面向屏内发射。 | 四面透明素纱围成边长 3 米的方形。向外射击可穿出，向内射击会在入屏处被拦。12 秒后收屏，拔起可提前收屏。 |
| 右二 · 铜叶样件 | 指向铜叶捏取，可在双手分别试拿、丢地与远取。 | 本场测试实物取放。双盘解锁、铜叶入腕匣与入档请在 [Chapter01_Courtyard](../../Assets/Scene/Chapter01_Courtyard.unity) 测。 |
| 右一 · 主榫样件 | 指向主榫捏取，松手后从地面重新拾回。 | 本场与二章共用清圭 R03 A。样件可近抓、远抓和掉地再取。清怪解锁和正式榫座的接受条件请在 [Chapter02_SuspendedPath](../../Assets/Scene/Chapter02_SuspendedPath.unity) 测。 |

工具带专属笔套以外的四个开口按实际尺寸、摆入方向和占用检查。主动放进合适的空槽优先。普通松手时，有归槽历史的道具在身体附近会尝试回原槽；手离身体水平约 0.60 米以上才算丢弃。原槽被占用或收不进就落地。

铜橛可在本场中间石台直接拾取。正式二章开局从工具带窄鞘拔出。独立[铜橛样板](../../Assets/Samples/ToolBeltItems/CooldownStakeLab.unity)另提供桌面取放模拟。[插地与拦截操作](SNAP_TOOL_ZH.md#定律铜橛隔离样板)

## 第二章工坊炉边

在 [Chapter02_SuspendedPath](../../Assets/Scene/Chapter02_SuspendedPath.unity) 测章节内的干粮教学。开新局，清完上层祭坛的三名守敌，乘 A 篮到中层，再到工坊木屋格窗前。面向能看到红炭的拱炉，四饼包和一块散饼并排放在炉口前沿。两件都可伸手捏取，也可用空手指向、看到射线命中后再捏合。

可以先拿散饼试吃，再拿整包。袋内仍有四块。受伤时在嘴前稍停可回复气血；满血时可以直接把布包靠近腰前工具带的中央软袋并松手。取整包和收进中央袋口会分别推进申屠的对应语句；也可以直接去取主榫。
