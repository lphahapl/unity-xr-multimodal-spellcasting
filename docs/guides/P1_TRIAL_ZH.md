# 考工律度 P1 反馈试炼

在 Unity 中打开 `Assets/Scene/KaogongP1Trial.unity`，按 Play。场景沿用现有官方追踪手、十二印实验台、技能目录和调试面板，当前用房间触发战斗，练习靶不推进旧三阶段流程。试炼使用独立存档文件 `kaogong-p1-trial.json`，默认从新角色开始。电脑调试栏展开「P1 试炼 · 音画与触觉」可查看服务状态。

| 操作 | 观察 |
| --- | --- |
| 摆寅印并说「火球术」，抬腕瞄准，出手击靶 | 观察碰撞、靶生命和命中特效。池达到容量时略过额外的视觉效果，继续结算命中。 |
| 从靶场走过通廊，越过战斗室内入口线；再退出 | 检查进出房间的战斗切换。恢复版的探索音乐保持静音，直到找到《一寸山河》v11。用真实麦克风说话时观察避让状态，讲话结束后背景音恢复。 |
| 点腕、合成火核、持核、出手、让定规障吸收攻击 | 检查腕部 UI 和法术音效。具备震动能力的握持手柄用于触觉实测；裸手重点观察声音、视觉以及触觉未发送原因。 |
| 用左食指选点、空手右手快推、点腕后关闭 | 复核既有 P0 交互，腕部悬停期间口令仍能进入匹配。 |

程序规范的优先级矩阵从 P1 开始。P0 在本场景指已有核心干路的阻断性回归，原交接的两条历史 P0 已复核，未证实为当前缺陷。本轮 P1 范围为 VFX 池、音频与触觉。试炼音频用于检查反馈链路，有正式音频资产时可在 Inspector 替换。编辑模式的设备模拟及 Play 集成均不能验证实际声场、手柄触感或 Quest GPU 帧耗。

恢复版采用 8 米通廊、14×16 米房间、单出生点与 Addressables 敌人池。场景的“对话”保留空句表，需要编排剧情时再填。[恢复验收、已接线范围和已知缺口](../research/DISK_RECOVERY_RESULT_20261107_ZH.md)。
