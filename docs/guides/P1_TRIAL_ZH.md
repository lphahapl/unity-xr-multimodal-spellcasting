# 考工律度 P1 反馈试炼

在 Unity 中打开 `Assets/Scene/KaogongP1Trial.unity`，按 Play。场景沿用现有官方追踪手、十二印实验台、技能目录和调试面板，当前用房间触发战斗，练习靶不推进旧三阶段流程。试炼使用独立存档文件 `kaogong-p1-trial-v2.json`，默认从新角色开始。电脑调试栏展开「P1 试炼 · 音画与触觉」可查看服务状态。

P1 现使用「线性训练场技能目录」，并通过 `TrainingChapterFlow.trialSkills` 常驻开放 `thunder.sword`。进入 P1 即可练习雷光剑，新旧训练存档均不要求永久解锁；完整口令为「雷光剑」，消耗 20 度力、冷却 4 秒、持续 8 秒。保持右手可追踪，召剑后横挥出横波、竖挥出竖波，两者都朝视线瞄准点飞行，持剑时显示方向提示。念「取消施法」或明确放低双手收剑；单纯丢失手部追踪只暂停判定并保留技能，恢复后继续握持，原持续时间照常计时。技能条件和效果参数见[雷光剑配置](CONFIGURATION_GUIDE_ZH.md#雷光剑与可选近战判定)。正式首章的学习进度不变。

Quest 独立包使用 `QuestVoiceBuild.RunP1` / `Build P1 Quest Voice APK`，输出 `Builds/Quest/Kaogong-P1-Quest-Voice.apk`。测试包使用独立应用 ID `com.kaogonglvdu.p1.voicecheck`，避免覆盖头显上使用相同 Unity 模板包名的「EP07气象与天文」。原生模型随包提供，首次需允许麦克风；故障可在腕匣「咒语」卡重试。构建与实际验收状态见[离线语音指南](SKILL_VOICE_SETUP_ZH.md)。

腕部入口放低可收起，已打开的教学卡保持显示，点「关闭」才收起；拖动松手只放置。左手离开追踪后，右手仍可射线轻捏翻页/关闭。火球这类“结印＋口令”术在术式教学和咒语索引均显示所需手印图。以上为工程修改，已安装 APK 需重新构建后才包含这些行为。

| 操作 | 观察 |
| --- | --- |
| 摆寅印并说「火球术」，抬腕瞄准，出手击靶 | 观察碰撞、靶生命和命中特效。池达到容量时略过额外的视觉效果，继续结算命中。 |
| 从靶场走过通廊，越过战斗室内入口线；再退出 | 检查《一寸山河》v11 与战斗 A 的切换。用真实麦克风说话时观察避让状态，讲话结束后背景音恢复。桌面循环与当前真机边界见[音乐实测](MUSIC_PRODUCTION_RUNTIME_ZH.md)。 |
| 点腕、合成火核、持核、出手、让定规障吸收攻击 | 检查腕部 UI 和法术音效。具备震动能力的握持手柄用于触觉实测；裸手重点观察声音、视觉以及触觉未发送原因。 |
| 用左食指选点、空手右手快推、点腕后关闭 | 复核既有 P0 交互，腕部悬停期间口令仍能进入匹配。 |

程序规范的优先级矩阵从 P1 开始。P0 在本场景指已有核心干路的阻断性回归，原交接的两条历史 P0 已复核，未证实为当前缺陷。本轮 P1 范围为 VFX 池、音频与触觉。试炼音频用于检查反馈链路，有正式音频资产时可在 Inspector 替换。编辑模式的设备模拟及 Play 集成均不能验证实际声场、手柄触感或 Quest GPU 帧耗。
