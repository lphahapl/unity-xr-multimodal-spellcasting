# 首章 · 苏醒

打开 [Chapter01_Awakening.unity](../../Assets/Scene/Chapter01_Awakening.unity) 后进入 Play。首次从试炼室醒来，后续启动读取 `Application.persistentDataPath/kaogong-chapter01-v2.json`。P1 练习场使用自己的场景与存档。v2 使用新文件名从新角色开始，原文件未删除，不做自动迁移。

开场会显示“正在按 ID 装配玩家技能”。看到关卡状态后即可结印、说口令或使用模拟施法。若加载失败，桌面调试面板显示具体原因和“重新加载技能”按钮。配置入口见[首章技能资源清单](CONFIGURATION_GUIDE_ZH.md#首章技能资源清单)。

## 关卡路线

抬起左腕，右食指按朱砂扣打开教学。探索移动沿头部水平视线前进，收回左手食指后在白石记号停稳。腕匣打开时可再次按扣收起菜单。按顺序命中近靶和侧靶，等度力恢复，再练护盾承伤与快推后撤。打倒试炼间的一具残机偶后，外门开放。

完成后撤教学会打开校靶内闸。站在门外仍可停留，玩家脚底跨入试炼间后才开始 `FT01`「当心那具残机偶」。紧接的 `FT02` 等本句音频结束和房间清空，再推进到外门。入口判定使用试炼间原有的区域盒，手、头和飞入室内的投射物均无法代替玩家脚底通过。

出门后沿脚边的白石嵌线直走，前方方框下是校规庭双盘台，左侧石刻给出图形线索，右侧叶匣装着方圆规印。右手轻捏铜耳，绕盘心移动指尖，然后松开。外盘转动会带动内方盘。横槽对上两端，方孔对准方销，两盘在容差内松手稳定后开盖。右手捏取方圆规印，送到左腕指定导轨入口松手。吸附完成后，把左腕靠近门旁校验座。校验门在台后偏右。过闸后沿右侧步道走到测候台。左侧石渠中的水顺坡向下，水尺旁较宽的水股从高处落入低渠。[路线平面](../visuals/20261108_compact_court/00_路线平面.png)

外盘初始 45°，内盘初始 20°。只把外盘转回水平，内方孔仍差 25°。转盘和取叶都要求右指尖在把手或铜叶中心 5.5 厘米内捏取。腕匣面板支持射线选项；庭内机关要用手靠近。

拿着铜叶，在左腕槽口 4.2 厘米内松手，关卡才会调用 NeuGameMRTools 的列表吸附。列表有三个随腕移动的目标。铜叶先从松手处用 0.10 秒对准入口，再用 0.18 秒滑到距入口 35 毫米的中段，最后用 0.18 秒滑到 70 毫米处的槽底。全程 0.46 秒。最后一段完成才登记入匣；随后把腕槽带到校验座 14 厘米内才开门。[SnapZone 配置](SNAP_TOOL_ZH.md) · [开场交付说明](../architecture/开场教学与首枚铜叶/00_交接说明.md)

## 当前外景与窗户

校规庭已扩为 17.9 × 10 米，东侧可以停步观景。苏醒室和实战间共十扇木格窗，窗外能看见工官校器坊、石基与山脊；主线、谜台和校验顺序保留。打开首章场景即可看到 `首章外景拓展 · 窗庭远山` Prefab。若编辑器仍持有改前场景，请先保留自己的未保存工作，再重新加载首章文件。[扩建实景与验证边界](../architecture/开场教学与首枚铜叶/07_校规庭与量水道制作单.md#当前扩建版窗庭远山)

外景细化已接入 `首章外景细化`：直坡工官建筑、校器台、层岩、山松、连续谷地及远山，具有实际LOD、太阳阴影与沿渠水声。三座校器坊和侧置门庭已接通步道与承托；测候天仪只转动完整内环。门庭已带头部进入触发组件，目的场景留空且加载关闭，当前不会传送；后续配置目标后再启用。[全景、模型预算与配置](CHAPTER01_EXTERIOR_VISUALS_ZH.md)

## 在 Inspector 中配置

RPG 的「章节流程（必填）」绑定 `OpeningTrialChapter`。教学内容由腕匣的 `TeachingCatalog` 提供，物品奖励由 `RpgItemInventory` 提供，永久技能校验门槛由首章的 `permanentSkillGate` 提供。训练靶生命在 `TrainingTargetGroup` 配置；商店有独立组件和商品目录。见[职责划分](../architecture/PROGRESSION_RESPONSIBILITIES_ZH.md)与[章节流程接入](CHAPTER_FLOW_ZH.md)。

| 对象 | 接线与生效条件 |
|---|---|
| 第一章根物体 · OpeningTrialChapter | `sections` 对应 RPG 的阶段与检查点。每组逐句绑定字幕、独立台词编号、旁白和操作。命中事件按阶段监听，其他操作按当前句注册，在通过、恢复或禁用时解除。 |
| 双靶与试炼间 | 两句分别引用自己的靶。仅玩家施法效果回报该靶命中时计入。本段教学已开始时，提前命中指定靶会保留到对应操作句，仍需等旁白结束；进入下一阶段、恢复检查点或禁用章节时清空，不跨段计数。战斗组件在实战句开启，异步生成单只敌人。 |
| OpeningDefenseDrill | 慢弹指向发射时的玩家身位，盾值足够才发射并结算。后撤需要实际向后移出训练带。 |
| 校规庭 · OpeningLeafPuzzle | 双盘独立把手、奖励匣、唯一叶片、左腕槽和校验座均为场景引用。外盘每 180 度、内盘每 90 度校准，默认容差 5 度，稳定 0.6 秒。掉落两秒回到支座。 |
| [首章阶段配置](../../Assets/ScriptableObjects/关卡阶段配置/首章) | 基础术式仍按原阶段的 `trialSkills` 借用，室外解谜不另增基础术式授权；校验成功后按原奖励写入角色进度。当前另为雷光剑提供全部 20 段的临时测试授权，见下节。 |
| [正式旁白](../../Assets/Resources/Narration/Chapter01) | 音频名相对 `Resources/Narration`。纯叙述等音频结束，动作句等音频和指定成功事件都结束。操作或解谜卡住会按阶段播放提示，打开腕匣并选择「结印」可重听当前引导。 |

外门、奖励匣和校验门从阶段存档重建。已取未入匣时，唯一叶片回到已开的支座。入匣后随腕显示，校验门仍等玩家在校验座出示腕匣。阶段 ID 同时用于存档，发布后的调整应保留已发布 ID 或提供迁移。

## 雷光剑临时测试授权与永久解锁

首章 `OpeningTrialChapter.sections` 的全部 20 段 `trialSkills` 含 `thunder.sword`，`initialDiscoveries` 也包含该 ID。「雷光剑」配方由首章清单按地址解析。玩家在各阶段领取临时试用，永久解锁由成长流程记录。普通输入、追踪、MP、冷却及占用校验继续生效。[首章技能资源清单](../../Assets/ScriptableObjects/技能目录配置/首章技能资源清单.asset)

需要配置永久获取时，从相应 `RpgStageDefinition` 的 `Unlock Skill Ids`（Inspector「解锁技能标识」）配置首次通关奖励，或从 [首章成长物品](../../Assets/ScriptableObjects/成长物品配置/首章成长物品.asset) 的 `unlockSkillIds` 配置物品激活奖励。物品独占技能不能同时配为初始或阶段奖励。`initialDiscoveries` 只表示了解；已有存档会载入自身进度，已领取的阶段奖励或已激活物品不会因为随后修改列表而自动补发技能，须另行设计明确的迁移方案。永久已解锁技能在首章仍须通过 `permanentSkillGate` 指向的 `GATE_CHECK` 才能施用；本轮雷光剑测试走临时授权分支。

授权验证与操作手感分别验收；桌面合成输入通过不等于头显真人操作已通过。

## 腕匣教学与铜叶

苏醒时可查两课。「火球术」需结寅印并念“火球术”。「护盾」有两种起手方式，结子印或单念“护体咒”，任选其一。腕匣可随时查已开放的课，室内具体能施哪一术由当前试炼段控制。

在庭院首次捏起方圆规印，腕匣即开放「金刚护体」的口令课，教学页显示“已了解／待解锁”。沿腕槽完成三点吸附后，存档才登记永久术式。玩家再向校验座出示左腕，才可在后续路段施用。可在[首章成长物品](../../Assets/ScriptableObjects/成长物品配置/首章成长物品.asset)配置物品 ID、收集时了解的技能与激活时解锁的技能；教学名称、配方分组和动作提示另在[首章术式教学](../../Assets/ScriptableObjects/教学目录/首章术式教学.asset)配置。首章场景当前投放一枚方圆规印。

铜叶的入匣参数在场景 `OpeningLeafPuzzle` 的「铜叶入匣手感」中：导向头本地坐标为 `(0, 0.07, 0)`，骨骼捏合松开距离为 0.035 米；腕部 UI 的松开阈值保持原值。释放时检查叶尖或最后握持位置，入槽后保留 0.25 秒接触记忆，允许手指自然张开时退让最多 0.10 米。右手短暂失追最多 0.35 秒只冻结铜叶，超时释放；真正的 UI 占用仍终止抓取。首章腕槽关闭触发器自动接管，只在本驱动确认松手且已开放插叶时启动三点吸附。捏住不吸、拿远不吸，掉落两秒召回规则保留。隔离 Play 的 14 项回归已通过，真人手感仍需头显复测。

## 行走和受击反馈

首章探索步速在 `OpeningTrialChapter` 的「首章探索步速」调整。当前为 1.25 米／秒，渠边平路 10 米的桌面实测时间为 8.00 秒。实际向前迈出才响脚步，松指或碰墙后站定即停。战斗改为指向地面刻线并驻留确认落点。[行走配置](ENCOUNTER_LOCOMOTION_ZH.md) · [战斗落点实拍](../visuals/20261108_trial_interior/Unity_战斗落点.jpg)

护盾全额承伤时沿用盾的反馈。玩家实际气血减少时，双眼边缘浮起朱砂色，约 0.58 秒消退，中央仍能瞄准。要调整强度，在[默认玩家](../../Assets/ScriptableObjects/玩家定义配置/默认玩家.asset)的「受击反馈」调整「视口边缘提示强度」；设为 0 可关闭。[同机位受击前后](../visuals/20261108_trial_interior/Unity_受击前后.jpg)

## 修改对白与字幕

在对应阶段的 `NarrationController → 逐句配置` 中展开一句，就能修改「说话者」和「台词正文」。[四列总表](../architecture/开场教学与首枚铜叶/03_Unity旁白导入.csv)可用于核对主线，给某段控制器重新导入时请选择对应的[分组表](../architecture/开场教学与首枚铜叶/ImportGroups)。读表规则见[旁白导入指南](NARRATION_FLOW_ZH.md)。首章 29 句主线从控制器读取正文，7 句卡住提示配置在相应阶段的 `hints`。

卡住提示按当前阶段的 `hints` 顺序播放。满足等待条件累计 18 秒后尝试第一条，后续每次累计 25 秒。某条找不到音频时，Console 会给出阶段和条目序号，并在同一次尝试里继续找下一条。禁用提示音源会暂停等待计时。

试玩使用一个世界空间字幕板。走动、转头时，一行小字保持在视口下方。每页保留说话人，开场可见「申屠：沈商，醒醒。」等台词。长句优先在标点处分开，依据当前音频的播放进度换页。音频结束后清空，即使这一步还在等待玩家完成动作也一样。
