# 《考工律度》沈商·五口下胸工具带与补给道具设定规范

## D 盘交互补充（2026-11-24 至 11-27 用户裁定）

五口均可交互。笔套专收墨规笔，其余四口均为通用口。下方云盘原稿列出的收纳道具是初始陈列示例。通用口空闲时，物件在放入姿态下的宽、厚、深能进入该口即可收纳，墨规笔也可放入尺寸合适的通用口。

道具记住最近一次实际取出的槽口和放置朝向。掉到地上后再捡起同一件，仍能归回该口。换槽时，将道具按收纳姿态送入另一个合法空口再松手，换放优先。再次从新口取出后，新口成为来源。

普通松手使用握点到玩家头部的水平距离。起测半径为 0.60 米，可随头显试戴调整。距离小于半径时，尝试回来源口一次。原口被占、放不下或吸附失败就落地。要主动丢弃，把手向身体外伸至半径边缘或更远再松开。玩家在场地里走动时以松手当刻的头部位置计算。从未从槽口取出过的道具，普通松手仍落地。

道具 SO 的六类建议为通用、墨规笔、青铜拓片、干粮包、松墨锭、定律铜橛。类型用于身份和默认陈列。四个通用口的接收条件取决于空位与空间。

## 一、 核心美术与配色规范

工具带与全套道具严格对齐沈商主设的低饱和烟靛灰褐粗布麻衣体系，禁用高饱和现代尼龙、战术快拆扣与发光魔法药水：

- 背板与布袋：烟靛炭灰褐粗织麻布，保留自然经纬织纹与低调同色系暗缝（无过密杂乱针脚）。
- 皮具与木件：熟旧焦茶褐革、胡桃木、蜜褐黄杨木（刻度尺梁）。
- 五金件：哑光冷铸旧青铜与微弱铜绿包浆。
- 识别点缀：褪色砖红朱砂布拉耳、沉稳灰绿蜡麻缠绳、本色麻绳结。

## 三、 已定稿道具详细设定

### 1. 墨规笔（方案三 · 汉代刀笔木铜双用型）

- 参考图：沈商_墨规笔_方案3_三视图.jpg
- 结构材质：胡桃木与黄杨木拼接笔杆（黄杨木面阴刻先秦寸分刻度），配可滑动青铜游标卡环与靛灰防滑蜡麻绳握段；前端牛角拼青铜笔斗纳盛唐鸡距硬毫；尾端为带小环的可拆卸青铜锥帽，拔下暗藏汉代微型熟铁削刀/划针（呼应“刀笔吏”修简改错逻辑）。
- 收纳方向：在工具带极左笔套内笔锋朝下收纳，上方仅露出黄杨木刻度段、靛灰缠绳与青铜锥帽，防止刮伤手部。

### 2. 回复气血 · 行旅麦枣干粮包（吃喝为主，可多次使用）

- 参考图：行旅麦枣干粮包_三视图与展开态.jpg
- 结构材质：本色粗麻扁圆布囊，顶端缝宽大褪色朱砂织物拉耳；内衬防潮油纸，叠放 4 块刻有十字分格纹的谷麦红枣干粮饼。
- 交互逻辑：

1. 任一手捏住朱砂拉耳从正中布袋抽出。
2. 拉耳用来从腰带抽包；拿稳后手托袋身下半部，粗麻与油纸在掌上摊开。四块麦枣饼相叠，露出可以捏住的饼边。取走一块后，下一块仍留在纸托上。
3. 取食一块举到嘴边（头显下方嘴部区）完成咀嚼回血，可分多次取食，吃净后收袋。

### 3. 回复度力 · 醒神松墨锭（预分块折断消散，可分次使用）

- 参考图：醒神松墨锭_概念图_定稿.jpg
- 结构材质：扁平可复用推拉盖松烟冰片墨块，配灰绿蜡麻绳握把与胡桃木青铜滑套（滑动打开供嗅闻醒神，无需折断即可多次回复度力）。
- 交互逻辑：

1. 使用一次时，沿着中间的预分块线干净断开（或掰下底段半块）。
2. 用掉的一半随即化作细碎黑墨尘与淡灰墨烟消散，同时为沈商回复度力（松弛生理发条负荷）。
3. 剩余带灰绿缠绳的上半块保留在护套中，可于下次继续使用。

### 4. 冷铸青铜拓片（用途待定，纯三视图先行）

- 参考图：冷铸青铜拓片_三视图.jpg
- 结构材质：约 2mm 厚的掌心矩形冷铸哑光青铜薄板，顶端居中带 U 形小缺口；正面阴刻先秦规矩方圆几何纹（槽内带微弱铜绿）及右上角微朱砂官印；背面保留冷铸锤打肌理与工匠戳记。
- 定位状态：按一次消耗品方向预留，具体玩法用途待定，当前仅交付正交三视图供 3D 建模先行制作。

### 5. 定律铜橛与四面素纱屏

- 铜橛形制沿用原概念图《定律铜橛_冷却加速力场道具概念图.jpg》。纱屏材质参照马王堆曲裾素纱单衣的单层透景、纱面交叠和缘边。[馆方实物照片](https://www.artmuseumonline.org/art/upload/image/2026/07/07/52027eb933db48878212eb52b86214ae.jpeg)
- 结构材质：适配极右第 5 槽窄鞘的修长冷铸青铜定脉立桩；顶部为八棱方孔铜盘配本色麻绳结（方便盲抽），中段嵌有一枚可高速旋动的青铜擒纵齿轮环（微带铜绿包浆），下端为刻有寸分尺线的八棱玄铁青铜探地锥。
- 二章开局铜橛随工具带配发。将锥尖朝下插地，齿环旋动，四面素纱围成一道方屏。纱身随风轻摆，暖光沿织缘游走；外来弹幕触屏时止住，并在命中处激起纱波。屏内可以向外还击，人物也可穿过纱面。十二秒后收屏，拔起铜橛可提前结束。[取放与拦截](../guides/SNAP_TOOL_ZH.md#定律铜橛隔离样板)
