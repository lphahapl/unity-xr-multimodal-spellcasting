# 首枚方圆规印与同心合矩解谜

玩家学会观察共同基准，再以双盘校正机关，获得第一片方圆规印。谜题名称“同心合矩”是本轮场景命名。机关位于校规庭，使用原有天工司几何修复语言。

## 机关构成

固定基座上有一个直径约32厘米的青铜圆台，外圆盘与内方盘共轴，但可独立转动。外盘有一条横贯圆心的直槽，基座两侧有一对固定的半圆基准标记。内盘有方形孔，基座固定方销的边与地面白石十字一致。旁边石刻画出“横槽连两端、方孔合方销”的完整状态，另有缺角旧工件供观察。线索依靠形状即能理解。

双盘初始角度故意错开，外盘相对世界45度、内盘相对世界20度。外盘转动时带动内盘一起转，内盘也能独立校正。外盘回正后内盘还偏25度，需要继续调整。因此先定外盘、再调内盘是容易理解的顺序。单手抓握两只大铜耳进行旋转，另一只手放松，不要求双手同时精确操作。

## 成功判据

1. 外盘横槽对准基座固定两端，角度对180度周期取模后误差不大于5度。
2. 内盘方孔边对齐固定方销，角度对90度周期取模后误差不大于5度。
3. 两项同时成立并释放抓握，稳定0.6秒，允许机构吸附到精确角度。
4. 两个有效位置各有形状匹配和清响反馈。达到总条件后固定销自然落入，发出一次较深锁定声，奖励匣开盖。

误差与稳定时间是待实机调优的起始参数。玩家可直接把两盘一次调对。任何顺序都以最终角度判据验收，不能要求听完某句或按固定次序才能成功。

## 铜叶及能力

奖励选择方圆规印，共用85毫米总长、70毫米插入段、15毫米共面环的现行实物母件。初始道具阵列只出现这一片，其余槽位保持可辨的空状态。

新档教学先开放火球与基础护盾。室内实际施法随试炼阶段开放，后撤沿用战斗移动规则。首谜依靠双手完成，不消耗度力。首次拿起方圆规印即开放「金刚护体」的口令教学；这一步允许读配方。入腕槽的三个吸附点全部完成才登记进阶护盾的永久资格，安全解谜段一直到校验完成仍维持施法限制。其他铜叶可按成长配置绑定其教学与术式，目前只有首枚有本章可交付的领取事件。

腕匣新圆盘中央方口继续保留现有形制。首谜的方销属于场景机关，不要求把铜叶尾环或插入端硬塞进腕匣圆盘中央方口。

## 失败和无障碍

转错只有未到位反馈。双盘各有大握耳和吸附辅助，持续单手操作可解。失去手部追踪时松开，锁住当前角度，恢复后重新抓握。离开庭院暂停提示。

铜叶掉到够不到的位置2秒后，回到已开的奖励匣支座，已获持有状态保留。出界、重载也恢复唯一实体。入匣完成后才允许永久归档该实体，杜绝重复生成和一片进度丢失。死亡只回室外检查点，解谜已通过则维持开盖。

旁白提示分三层，第一次提醒观察石刻，第二次明确横槽对应基座两端，第三次说明方孔四边对应方销，逐级间隔至少25秒，玩家可主动索取。色觉以槽线、方形轮廓、盘上凸刻和声音互补。解谜失败不复活敌人，不扣资源。
