# 试炼室外的场景与线性路线

正式选型沿用 B 组的校规庭与 C 组的量水道。沈商从亚稳定区的木格窗试炼室跨出外门，先凭脚下嵌线和台后方框找到谜台。左侧垂锤仍然向下，旁边重梁已经脱离榫座。水准失效的主景留给校验门后的石渠。世界依据见[世界观白皮书](../../world/考工律度_世界观设定白皮书.md)。

## 路线节点

| 节点 | 画面和引导 | 离开条件 |
|---|---|---|
| R00 试炼室外门 | 门框正对谜台，嵌线从门槛延向台前 | 室内试炼通过，再跨出门槛 |
| R01 关外石坪、R02 折尺廊 | 小坪和短廊并入校规庭前口，共用正前方目标。侧廊有围栏 | 沿路通过原有两个阶段触发区 |
| R03 校规庭 | 左石刻、中双盘、右奖励匣，真实准望匣佩在左腕 | 手动合矩、取得第一枚方圆规印，按原三点列表吸附入匣 |
| R04 校验门 | 从谜台右侧绕行即可到校验座，后墙遮挡水渠 | 用腕匣完成资格校验后开闸 |
| R05 量水道 | 平坦步道左侧是敞口石渠和直立水尺，尽头看得见天仪 | 沿水道走到平台 |
| R06 测候台 | 天仪断轴收住视线，平台可停步回望 | 触发章节完成并存档 |

2026-11-08 外景扩建后，校规庭从 11.2 × 10 米拓为 17.9 × 10 米。两间房合计十扇木格窗能看见外围石台、远亭和山脊；远处设四面不可见边界。可见世界变宽，谜台、门锁、导航点和章节触发仍沿原线排列。从外门到测候台的目标长度约 30 米，主谜题保留操作空间，室外没有新增强制战斗。门口、庭内和渠边的空间关系、性能取舍及派工见[定向制作单](07_校规庭与量水道制作单.md)。

## 第一轮候选图档案

以下保留 33 张候选图的制作要求，供核对 B、C 两组元素来源。当前首张实景按门框、白石线和双盘台构图。

### 外景出图提示词（失度修订）

每组使用下列对应提示词，分别交十张独立构图和一张独立的 2:1 全景，共 33 张。各机位变换观察位置与朝向，例如从门内向外、沿护栏侧看断面、回望来路。每张同时保留脚下路线、工官建筑、侧路巡逻的残机偶，以及无需文字便可辨认的一项中景异常。用同一物体、相同构件或清楚的接触痕迹来表现差异。首张优先验证物理关系和可走方向。全景拓展左右视野，同时保留近处参照。

**A · 关外石坪与折尺廊。** 第一人称站在半开的厚石闸内，一线檐水落进脚边浅石槽，溅湿下方石面。沿着同一槽看向栏外，水从缺口拐向头顶断层，水珠拖向上方，梁底迎水面留下湿痕。附近半截重柱悬离可配对的柱座，榫头与座孔间透出天光。中间一条磨白的平石路转入折尺廊，下层维护道有一具木骨铜甲的残机偶拖着规刃巡行。以门框和廊柱标定真垂直；逆水出现在抬眼可见的位置。

**B · 校规庭。** 沿轻转的白石路缘入庭；左是残缺几何石刻，中央是能伸手够到的外圆内方双盘，右是可见铜叶的闭合奖励匣，后方校验闸紧闭。近处铅锤自直角尺架垂下；沿同一排梁看过去，栏外一根完整重梁横向脱榫停在半空，露出梁端榫头、对应空座和落在下层墙面的投影。同排完好梁仍坐入榫肩。残机偶在侧廊两根柱间巡行。让人一眼分出可摸的谜台、必须修的机关、失衡的外界。解开双盘只开叶匣，校验后才开闸。

**C · 量水道与测候台。** 沈商站在有低护栏的检修步道，同一条量水渠从脚边顺坡向下，水台阶底部留着真实水花。中景水股脱离石槽，向更高的暗紫近黑断层爬升，露出本应浸湿的低处渠床；并排水尺和直立栏柱让水位高差可量。路尽头的破损测候台仍是地标，一具残机偶沿对岸低层检修道巡逻，身后跟着一道不连轴的天仪铜环。远景从简，视觉重心留给这股违反水准的水。

统一器物采用先秦天工司的青灰石、汉白冷玉、青冈栎木与哑光青铜。朱砂用于锁止和危险标志，青玉用于已校准的机关。禁用满屏能量雾、发光圆罩、倾斜镜头、远天散布的小浮石和普通古镇风光来代替可查的失度。巡逻者走侧路，首谜前只有室内那场强制战斗。以上是历史概念选图要求，正式外景已采用 B 主体加 C 水道；现行扩建见制作单。

单张验收时，悬浮主构件的顶底都要露出间隙，轮廓不能贴着屋梁或藏进烟雾。逆流要画出低处敞口的源头和高处的冲击水花。若遮住标题仍像屋顶漏水，或像一根从房梁吊下的柱子，就换机位重出。


## 声音与舒适度

关外先有风声、极远的金属颤音和一两滴水声。校规庭以各盘的低频机械止动声、到位清响、奖励开盖声提供连续反馈。语音期间音乐降约6分贝，环境降约8分贝作为混音起始建议。攻击预警保持可辨。

无强制摄像机摇移，无自动滑入深渊的桥段。路径宽度建议2.4米以上，机关台前净空约2.5米，保留坐姿够取范围。正式宽度、碰撞和追踪在头显中验证。旁白为腕匣近身清晰语音，机关与环境采用位置声。
