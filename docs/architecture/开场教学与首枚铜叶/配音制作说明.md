# 开场旁白制作说明

本轮试玩中，沈商的师傅申屠从左腕准望匣里的留音青铜铎传声。29 句主线根据玩家操作与关卡阶段触发，7 句提示在当前步骤停留时播放。每句准确台词与推进条件见[主台本](02_旁白台本.csv)，字幕按同一 lineId 存在[字幕表](字幕.csv)。

## 音色与表演

本地 QwenTTS 声音工作台 Voice Clone Studio 使用两段用户参考录音。audio.wav 对应「旁白_常态.wav」，SHA-256 为 25d2697fb6d242c5ddda2276c7a1e491cc5f2c9403bfefc42129745ea9e623f6。audio (1).wav 对应「旁白_愤怒.wav」，SHA-256 为 b53c2432850d496f9fb79bbd503fca959e6c36fc59058eadc9ca300cd4b61ff8。

FT01、FT02 及战斗提示 HT01 使用愤怒参考，师傅急声护徒。其余 33 句使用常态参考。每句的表演意图、所用参考、判别结果、转写、返录轮次、时长与最终 WAV 哈希可在[逐句审批](逐句审批.csv)和[音频清单](audio_manifest.json)中核对。技术审批已通过，角色听感与专名发音留给试玩试听；本轮接入源于用户对试玩版本的确认。

## 导入与核查

- [正式音频](../../../Assets/Resources/Narration/Chapter01)逐句使用 48 kHz、16-bit PCM、单声道 WAV。场景、重听和提示使用 Chapter01/ 下的稳定文件名。
- [主线导入表](03_Unity旁白导入.csv)记录 29 句。ImportGroups/ 按主线及提示分别分成 27 组。导入器读取 audioFileName、speaker、delayAfter 和台词正文 text；原有操作条件、事件和阶段 ID 由场景及关卡配置维护。
- [验证结果](validation.json)记录实测总时长、采样格式和文件一致性。每条音频的 duration 按实际 PCM 帧数计算；核对音色时，可从逐句审批表的文件列定位同一段音频。
