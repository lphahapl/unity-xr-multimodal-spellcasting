# 开场教学与首枚铜叶交接

2026年11月7日正式采用。20 组教学和路线事件见[首章实现说明](../../guides/CHAPTER01_AWAKENING_ZH.md)，36 段配音见[正式音频目录](../../../Assets/Resources/Narration/Chapter01)。

## 已定流程与边界

首章引导者为老考工官申屠，沈商的师傅。他的意识寄在左腕准望匣，借匣内留音青铜铎传声。配音和字幕按同一说话人归档，教学与外景均无需师傅模型、立绘或投影。11 月 8 日试玩采用按用户两段参考音色重录的 36 句申屠配音。机器转写、音色和时长复核及人工听审关注项见[配音复核重点](06_配音复核重点.md)。

设木格窗的试炼室苏醒 → 腕匣与行走 → 火球打靶 → 调息 → 护体 → 快推后撤 → 一次残机偶实战 → 出门 → 入口短廊 → 校规庭手动解谜 → 获得方圆规印 → 入指定腕匣槽 → 铜叶校验开闸 → 量水道 → 测候台。关外石坪与折尺廊的两个存档阶段共用入口小坪和短廊。

入室时腕匣无铜叶，教学页先开放火球和护盾两课。室内借用术式的范围由当前试炼决定；安全解谜段收回临时施法权限。实际拿起首片方圆规印后，腕匣开放「金刚护体」口令教学，标记铜叶待入匣；三点吸附完成后登记永久资格，闸门校验完成后可在正常施法区域使用。后撤沿用战斗移动教学。各段的借用与校验后授予见[首章配置与接线](../../guides/CHAPTER01_AWAKENING_ZH.md)。

方圆规印从校规庭实物匣获得，首谜可完全依靠抓握与旋转完成。全套只授予这一片。首谜通过与入匣成功分别持久化，奖励对象使用唯一 ID，掉落可召回，载入不重复发片。

## 文件用途

- 01_室内教学流程.md 给出节点、完成谓词、重试和训练节奏。
- 02_旁白台本.csv 是台词及事件主表，含稳定步骤和台词 ID。
- 03_Unity旁白导入.csv 含 audioFileName、speaker、delayAfter、text 四列。按 controllerGroup 分段导入文件收于 ImportGroups。
- [室外路线](04_室外场景与线性路线.md)与[校规庭、水道制作单](07_校规庭与量水道制作单.md)记录 B 主体、C 水道的选型、门槛视线与分工。
- 05_首枚铜叶解谜.md 定义机关状态、容差和领取判据。
- 正式音频目录按 lineId 存放每句 WAV。提示按当前步骤独立播放。
- audio_manifest.json 记录实际音频参数、哈希和检查结果。
- 配音制作说明.md 记录音色、技术参数、转写和验收状态。

## Unity 接线

场景使用 29 句主线与 7 句分级提示。主台本与分组导入表已随本目录归档。音频使用 Chapter01 子路径，哈希与转写以 audio_manifest.json 为准，其中 file 指向对应的正式 WAV。

原暂存目录的 READY_TO_MOVE.json 记录交付时间，正式资源直接从该目录移动。

03表及ImportGroups内的audioFileName已预置Chapter01/前缀，对应正式Resources子目录。主台本保留纯WAV文件名供本地查找，lineId不变。导入后的ResourcePath应为Narration/Chapter01/WK01等路径。

每组独立 NarrationController，读取台本 controllerGroup。只有本组主流程行导入其分段 CSV，提示句由独立提示控制器管理。稳定 stepId、lineId 为外部内容标识，NarrationController 内部 Id 仍是本组从零开始的列表下标。

操作行使用“音频和操作都完成”，纯叙述行使用“自动继续”。步骤开始前启用相应监听，结束立即解绑。将指定对象的实际业务成功绑定 PublishCurrentOperation，避免任意靶命中或其他吸附事件跳过步骤。已满足持久条件时，在步骤开始后立即通知当前控制器。不要把主表中的 eventKey 当成现有系统已经支持的事件字符串。

OpeningTrialChapter 负责当前步骤监听、提示与读档，OpeningDefenseDrill 负责护盾和后撤练习，OpeningLeafPuzzle 负责双盘与唯一叶片。

## 提示和存档

玩家有效参与但18秒无进展给一级提示，再间隔25秒给二级提示。只在对应步骤、语音通道空闲时播，每级本次停留最多一次。暂停、菜单、追踪失效不累计计时。战斗以简短预警为先，长旁白留到开战前或清场后。

按阶段存档，回档先重建对象和权限，再恢复相应旁白段。玩家可在腕匣重听当前引导。字幕在视口下方固定位置显示一行「说话人：正文」；较长的句子按停顿分页，音频结束后清空。

依据为两份世界设定、现行 V3.6 铜叶规范、NARRATION_FLOW_ZH.md 和实际源码。新增地点、机关及临时授权均为本轮方案。实机舒适度、难度和配音听感待验收。
