# 六种基础手印设计

状态：2026-11-25 核对当前六份配置。规、矩、律、衡已有规则，准、绳仍待真人采样；六印已绑定各自成印字影与确认音。字影沿用首版。用户退回偏刺耳、电子感的V2后，五个确认音已换为既有器物拟音剪辑的V3，仍可批注；不将配置或历史录制回放当成本次头显实测。

正式活动集合为 **规、矩、律、准、绳、衡** 六印。保留原手形中辨识特征不同的六种，让名称与《考工律度》的器具、测度和工匠动作相连。玩家看到的短名统一为“规印”等；“合规、交矩、鸣律、平准、张绳、镇衡”作为教学记忆词，不增加另一套必须记住的术语。

## 六印及原型

以下动作描述用于辨认现有图片；左右手、指节接触与朝向应以保留的原图和实录样本为准。识别优势是设计判断，不能由图片直接推出 Quest 成功率。

| 新名称 | 原型与教学图 | 主要轮廓与记忆词 | 术式含义及使用方向 | 当前配置 |
|---|---|---|---|---|
| **规印** | [子](../../Assets/Resources/Teaching/Seals/规印.png) | 一手包合另一手竖起的手指，形成紧凑的合抱轮廓；**合规** | 收拢、围合、守界。施放规印加持；可以作为护持类术式的基础手形。 | 已有标定规则 |
| **矩印** | [丑](../../Assets/Resources/Teaching/Seals/矩印.png) | 两手交错，一横一竖，突出交叉关系；**交矩** | 定向、转折、构形。适合后续几何机关和方向控制；不表示弹道反射已实现。 | 已有标定规则 |
| **律印** | [寅](../../Assets/Resources/Teaching/Seals/律印.png) | 双食指并拢向上，其余手指合扣，形成双柱；**鸣律** | 起律、激发、成核。“律印＋火球术”激活火球。 | 已有标定规则 |
| **准印** | [申](../../Assets/Resources/Teaching/Seals/准印.png) | 两手平展交叠，指向相反，整体横向延伸；**平准** | 校齐、平定、稳定。适合水位、平台或机构校准的后续设计。 | 空模板，需采样 |
| **绳印** | [午](../../Assets/Resources/Teaching/Seals/绳印.png) | 双食指斜向相接成顶角，下方展开，形成张开的三角轮廓；**张绳** | 牵引、联结、约束。取张绳成线之意，不要求真的拉开双手。 | 空模板，需采样 |
| **衡印** | [左手实录教学图](../../Assets/Resources/Teaching/Seals/衡印.png) | 左手单独结印；以当前实录规则及教学图为准，**镇衡** | 左手护盾、承重、配重、镇定。与准印的“校齐”区分，强调力与重量。 | 已有单左手标定规则 |

规、矩、律的 `calibrated` 为真，均有 45 条规则条目；其中正权重条目分别为 7、10、9。衡印为 `LeftOnly`、`calibrated: 1`，使用 2026-11-27 新录制的 210 个有效左手观测生成 18 条规则区间，保持时间 0.15 秒。腕匣与首章教学板的手形图来自同一次录制。旧录制仅供回查，相近手形仍按当前模板评分。准、绳为 `calibrated: 0` 且规则为空。成印反馈资产完成不会自动使未标定模板参与识别。

## 六种不再进入主教学集合的原型

| 原型 | 筛除原因 |
|---|---|
| 卯 | 局部伸指、勾扣关系较细，需要和指向、近捏等基础交互一起排查误触；六种名额优先给整体轮廓更明显的原型。 |
| 辰 | 多指合扣，关键差异落在下方小指和局部接触关系，教学与可见性成本较高。 |
| 巳 | 整体接近双手合抱，容易与规印争夺记忆特征；本身没有现成标定规则可复用。 |
| 未 | 直立窄轮廓与保留的律印接近，主要区别偏向局部指形。 |
| 酉 | 与午都有指尖相接的三角轮廓；只保留午，避免六印中同时教授两种近似顶角。 |
| 亥 | 闭合双手、下垂指形较多，相比平掌和覆拳不易用一句话区分。 |

这是候选集筛选，不是上述六种已被实测判定“无法识别”。迁移时保留原始图片、录制与配置历史，仅从正式活动列表移出，不直接销毁。

## 与铜叶及首章的关系

铜叶负责解锁术式，手印负责施术时的动作输入，二者没有一一对应的数量约束。继续保留五种铜叶及圆盘上的 **规、矩、律、准、绳**；增加衡印不增加第六种铜叶，也不把用户已定的“律”改回“衡”。铜叶全名仍为方圆规印、勾股矩印、负衡律印、平准水度、直绳雷度。

首章仍只教两种：衡印施放护盾，律印承接火球组合。其余四种随相关术式和机关教学逐步引入，不在第一次教学连续要求六印，也不把每次施法改成六印连招。矩印已有规则并不意味着它必须在首章开放。

同一手印可以配不同口令选择术式，保持已有 GestureOnly、VoiceOnly、Combination 三种触发方式。衡印护盾支持单左手结印和直接念“衡印”两种方式，首章教学同时展示。独立雷光剑样机沿用纯口令。技能 ID、解锁记录和伤害数值不属于此次设计变更。

首章护盾与火球的两种手法统一显示为衡印和律印，沿用 `HENG-SHIELD-UNIFY-20261123` 的已实施命名。

## 教学与识别约束

每张教学卡使用短名、实际手形和一句口诀：**合抱成规、交手成矩、并指成律、平掌成准、张角成绳、左手结衡印**。成印标记可分别采用圆环、折角、双竖线、水平基线、张线三角、承重横梁；图标是记忆辅助，不能代替手形图。

保持原型中稳定且舒适的接触，不要求用力挤压指节。若为减少遮挡而放松穿指、改变双腕距离或左右手关系，视为姿势改版，必须补采样；不能继续宣称完全复用了原标定。左右镜像也不默认自动等价。

采样验收至少覆盖六印相互混淆、从自然放松到成印的过渡、不同观察角度，以及近捏、指向、开掌、腕菜单、拿铜叶等日常交互。重点检查规/衡、律/绳、准/矩；静态姿态能识别还不等于过渡过程不会误判。保留低置信拒绝与候选分差机制，先根据实录调规则，再确定各印保持时间，不在设计稿里凭空降低阈值。

## 成印字影与声音 V3.1

六份配置各自绑定 `Assets/Art/VFX/Skills/SealConfirmation/` 中的 `{Gui,Ju,Lv,Zhun,Sheng,Heng}SealFlash.prefab`。律印原样板保留。五个新字沿用原样板的程序化暖金笔画、细暗边和 0.8 秒扩散淡出；属于原创篆意游戏字形，不声称是古文字考据复刻。

| 印 | 字形主要差异 | 确认音意图 | 识别与制作边界 |
|---|---|---|---|
| 规 | 左侧交叉、右侧目形与分开的足部 | 柔软摩擦回拢收口，表达围合守界 | 已绑定，双手 |
| 矩 | 右侧方折开口，短横直角结构 | 包裹的木面短转角，表达转折成形 | 已绑定，双手 |
| 律 | 保留原曲线、笔形及下部双柱 | 原律印金石音 | 原样板与原引用不变 |
| 准 | 水旁短笔、水平齐列 | 平缓抽擦平复，表达校齐稳定 | 已绑定模板；仍待真人采样 |
| 绳 | 左侧折线、右侧上下结形 | 连续抽拉束紧，表达联结约束 | 已绑定模板；仍待真人采样 |
| 衡 | 三部横向分布、下部承托 | 低厚承托后余动落稳，表达承重镇定 | 左腕原锚点；独立材质深度偏移 0.12 米，头显遮挡待验 |

V3.1沿用用户指定的项目Battle Sound Library材料和摩擦原件，通过不同截取、层增益、时序与有限瞬态控制分配力度。规将重点放到回拢后的收口；矩突出短木靠合；准减少底擦，轻点后稳住；绳延长真实抽拉形成连续牵引；衡增加木体承托并保留自然阻尼。律印铜鸣原样。柔和由音头、材质与收尾表达，不等同于整体降低音量，也不要求五印低于律印或统一峰值、RMS、K加权能量。五音48kHz单声道PCM16、0.35–0.54秒；峰值、20/100/400ms能量及相对律印数值仅是描述，不作等响验收条件。GUID、字形、Prefab及识别配置不变。使用的是库内作者拟音剪辑，不声称新录了圆规、绳或秤。[V3.1来源、试听与验证](../../ArtSource/Audio/SealConfirmationV3_1/README.md) · [六印原设计增益对比](../../ArtSource/Audio/SealConfirmationV3_1/comparison_original_gain.wav) · [V3/V3.1对照](../../ArtSource/Audio/SealConfirmationV3_1/AB_V3_V3_1.wav) · [V1字影制作](../../ArtSource/VFX/SealConfirmationV1/README.md)。

小尺寸验收使用同一亮度和背景，把实际贴图缩至96、64、48像素并打乱顺序，先识字、再区分相近轮廓；在实际手部尺度检查峰值、消散和腕匣遮挡。声音的主要验收使用实际设计增益和游戏播放设置，检查动作特点、材质区分、叠音余量与耳侧舒适；可另做响度匹配的盲听来排除纯响度提示，但该对照不回写生产音量。记录误认与疲劳感，重点比较规/衡、律/绳。桌面资产检查不替代Quest双眼、手部噪声、腕菜单及实机混音验收。

## 工程迁移范围

当前 `SealProfile.sealName` 同时承担识别和技能匹配，教学图也以名称拼接资源路径。本次迁移涉及以下环节：

1. 六份保留的 SealProfile、活动列表及测试预期；保留原资产 GUID，先归档原始证据。其余六印退出活动列表。
2. 技能配方中的 `sealName`、首章课程、字幕和教学提示；不更换技能 ID 或铜叶 ID。
3. `Assets/Resources/Teaching/Seals/` 的取图名称与 `.meta`，同步腕菜单和测试 UI；保证旧配置迁移期间不会丢图。
4. 实验台构建和引导采样共用六印名录。测试标题、权重 JSON 与录制标签均使用正式印名。读取旧录制时映射保留印的标签。
5. 首章 FR01 与 SH01 沿用原句的角色音色补录；当前用语分别为律印与衡印。
6. 两份世界设定、首章设计和操作指南、程序/策划/美术/音频需求及参考表，分别记录当前版本和历史资料。

头显验收目标是：活动集合恰好六印；技能与教学图能按新名称解析；首章两印、纯口令路径和腕部基础交互不回退；准印、绳印、衡印完成实际采样并通过六印混淆检查。当前规印、矩印、律印可用于有序配方。衡印使用单左手录制模板。准印、绳印仍为空模板，六印混淆测试待完成。
