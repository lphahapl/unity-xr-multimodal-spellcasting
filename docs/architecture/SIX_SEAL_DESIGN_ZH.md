# 六种基础手印设计

状态：2026-11-08 设计提案；筛选和新名称已明确，尚未迁移运行时配置。依据恢复后的工程与十二张教学手图，不将旧记录当成本次头显实测。

建议将十二地支手印收敛为 **规、矩、律、准、绳、衡** 六印。保留原手形中辨识特征不同的六种，让名称与《考工律度》的器具、测度和工匠动作相连。玩家看到的短名统一为“规印”等；“合规、交矩、鸣律、平准、张绳、镇衡”作为教学记忆词，不增加另一套必须记住的术语。

## 六印及原型

以下动作描述用于辨认现有图片；左右手、指节接触与朝向应以保留的原图和实录样本为准。识别优势是设计判断，不能由图片直接推出 Quest 成功率。

| 新名称 | 原型与教学图 | 主要轮廓与记忆词 | 术式含义及使用方向 | 当前配置 |
|---|---|---|---|---|
| **规印** | [子](../../Assets/Resources/Teaching/Seals/子.png) | 一手包合另一手竖起的手指，形成紧凑的合抱轮廓；**合规** | 收拢、围合、守界。承接现有子印加持；可以作为护持类术式的基础手形。 | 已有标定规则 |
| **矩印** | [丑](../../Assets/Resources/Teaching/Seals/丑.png) | 两手交错，一横一竖，突出交叉关系；**交矩** | 定向、转折、构形。适合后续几何机关和方向控制；不表示弹道反射已实现。 | 已有标定规则 |
| **律印** | [寅](../../Assets/Resources/Teaching/Seals/寅.png) | 双食指并拢向上，其余手指合扣，形成双柱；**鸣律** | 起律、激发、成核。保留现有“寅印＋火球术”的组合，迁移后显示“律印＋火球术”。 | 已有标定规则 |
| **准印** | [申](../../Assets/Resources/Teaching/Seals/申.png) | 两手平展交叠，指向相反，整体横向延伸；**平准** | 校齐、平定、稳定。适合水位、平台或机构校准的后续设计。 | 空模板，需采样 |
| **绳印** | [午](../../Assets/Resources/Teaching/Seals/午.png) | 双食指斜向相接成顶角，下方展开，形成张开的三角轮廓；**张绳** | 牵引、联结、约束。取张绳成线之意，不要求真的拉开双手。 | 空模板，需采样 |
| **衡印** | [戌](../../Assets/Resources/Teaching/Seals/戌.png) | 一手握拳，另一手平掌覆于拳上，形成承托和压合关系；**镇衡** | 承重、配重、镇定。与准印的“校齐”区分，强调力与重量。 | 空模板，需采样 |

前三种配置的 `calibrated` 为真，均有 45 条规则条目；这只说明已有配置，不代表各条都有有效权重，也不代表本轮验证了识别效果。后三种当前 `calibrated` 为假且规则为空。

## 六种不再进入主教学集合的原型

| 原型 | 筛除原因 |
|---|---|
| 卯 | 局部伸指、勾扣关系较细，需要和指向、近捏等基础交互一起排查误触；六种名额优先给整体轮廓更明显的原型。 |
| 辰 | 多指合扣，关键差异落在下方小指和局部接触关系，教学与可见性成本较高。 |
| 巳 | 整体接近双手合抱，容易与规印争夺记忆特征；本身没有现成标定规则可复用。 |
| 未 | 直立窄轮廓与保留的律印接近，主要区别偏向局部指形。 |
| 酉 | 与午都有指尖相接的三角轮廓；只保留午，避免六印中同时教授两种近似顶角。 |
| 亥 | 闭合双手、下垂指形较多，相比平掌和覆拳不易用一句话区分。 |

这是候选集筛选，不是上述六种已被实测判定“无法识别”。迁移时保留原始图片、录制与配置历史，仅从正式活动列表移出，不直接销毁。

## 与铜叶及首章的关系

铜叶负责解锁术式，手印负责施术时的动作输入，二者没有一一对应的数量约束。继续保留五种铜叶及圆盘上的 **规、矩、律、准、绳**；增加衡印不增加第六种铜叶，也不把用户已定的“律”改回“衡”。铜叶全名仍为方圆规印、勾股矩印、负衡律印、平准水度、直绳雷度。

首章仍只教两种：规印承接子印加持，律印承接火球组合。其余四种随相关术式和机关教学逐步引入，不在第一次教学连续要求六印，也不把每次施法改成六印连招。矩印已有规则并不意味着它必须在首章开放。

同一手印可以配不同口令选择术式，保持已有 GestureOnly、VoiceOnly、Combination 三种触发方式。现有纯口令的护体咒、金刚护体及独立雷光剑样机不因这次命名自动增加结印要求。技能 ID、解锁记录和伤害数值不属于此次设计变更。

现行世界设定中的“规印·阖、权印·开”与实际“子、寅”配置并不一致。本提案将首章两印统一为规印、律印；旧“权印·开”作为待替换的早期名称，不另设第七印。

## 教学与识别约束

每张教学卡使用短名、实际手形和一句口诀：**合抱成规、交手成矩、并指成律、平掌成准、张角成绳、覆拳成衡**。成印标记可分别采用圆环、折角、双竖线、水平基线、张线三角、承重横梁；图标是记忆辅助，不能代替手形图。

保持原型中稳定且舒适的接触，不要求用力挤压指节。若为减少遮挡而放松穿指、改变双腕距离或左右手关系，视为姿势改版，必须补采样；不能继续宣称完全复用了原标定。左右镜像也不默认自动等价。

采样验收至少覆盖六印相互混淆、从自然放松到成印的过渡、不同观察角度，以及近捏、指向、开掌、腕菜单、拿铜叶等日常交互。重点检查规/衡、律/绳、准/矩；静态姿态能识别还不等于过渡过程不会误判。保留低置信拒绝与候选分差机制，先根据实录调规则，再确定各印保持时间，不在设计稿里凭空降低阈值。

## 工程迁移范围

当前 `SealProfile.sealName` 同时承担识别和技能匹配，教学图也以名称拼接资源路径。正式改名必须一次核对完整链路：

1. 六份保留的 SealProfile、活动列表及测试预期；保留原资产 GUID，先归档原始证据。其余六印退出活动列表。
2. 技能配方中的 `sealName`、首章课程、字幕和教学提示；不更换技能 ID 或铜叶 ID。
3. `Assets/Resources/Teaching/Seals/` 的取图名称与 `.meta`，同步腕菜单和测试 UI；保证旧配置迁移期间不会丢图。
4. `SealLabBuilder` 的十二名种子、`SealGuidedCapture` 的子丑寅白名单、识别测试的“十二印”标题，以及配置权重 JSON 和录制标签。原录制标签通过映射使用，不覆盖旧数据。
5. 已录旁白中真正说出的子印、寅印，需要换词返录，并核对音频播放顺序；仅改字幕不能算音画同步完成。
6. 两份世界设定、首章设计和操作指南、程序/策划/美术/音频需求及参考表，分别记录当前版本和历史资料。

迁移完成条件是：活动集合恰好六印；技能与教学图能按新名称解析；首章两印、纯口令路径和腕部基础交互不回退；午、申、戌完成实际采样并通过六印混淆检查。当前文档完成的是设计，以上配置、场景、脚本、音频与世界原典尚未修改，未运行 Unity 或 Quest 验收。
