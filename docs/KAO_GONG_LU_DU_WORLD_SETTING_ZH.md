# 1. 第一篇：世界观底层架构与神学本源 (Core Worldbuilding Bible)

### 1.1 一句话神学与世界本源
太古天地，如同一座运转不息的宏大机械天钟，以度、量、衡、规、矩、准、绳锚定乾坤常数。
当大钟发生“大脱扣”，主轴崩断，齿轮散落，天地彻底“失度”：
* **悬石与乱象**：万斤巨岩如柳絮浮于半空，神道断成深渊，地火乱冒如电路漏电；
* **残机狂乱**：古代天工司建造的青铜机关（**残机偶**）发条脱速倒转，盲动杀人；
* **勘律使与方圆界**：凡人身置失度风暴瞬间粉碎，唯有主角**勘律使（沈商）**佩戴上古天工司冷铸的【准望匣】，周身辟出一丈见方的【方圆界】。方圆之内乾坤稳固，方圆之外万象失衡。
* **度力与肉身**：主角并非呼风唤雨的仙人，而是凡人之躯。施法消耗的是肉身调控尺规的【度力】（筋骨心力）。连放四核度力告竭，停步调息 2 秒，气血平顺，度力自回。

### 1.2 画符的世界观根源：墨规定天地
在世界观中，**画符绝非道士求神捉鬼的鬼画符，而是天工司以墨绳度天地的【墨规】**：
* **天地残缺的零件修复**：古神庙的大门与机关并非被法力封印，而是其上的精密几何卡扣因大劫磨损断裂。勘律使拔出【墨规笔】，以朱砂磁墨在面前青铜光栅画板上补全残缺的正圆或方矩，本质上是在“为天地补齐磨损的几何零件”；
* **工匠凝神专一之志**：执笔之时，神意贯注于笔尖毫厘，体内气机闭锁，绝不可分心挥拳出招；
* **战前冷铸拓片**：在安全区调息凝神，以墨规笔在画板上勾勒【金石护身纹】，结合准望匣喷吐的冷熔铜粉，可在白汽中冷铸出一枚随身携带的【金石护身拓片】，战时捏碎硬抗致命一击。

# 3. 第三篇：普适四阶段施法全生命周期 (Universal 4-Stage Casting Lifecycle)

全法术普适状态机，彻底废除单一火球 7 阶段划分：

```
[定 势]       ➔       [结 印]       ➔       [印 成]       ➔       [运 法]
双手平放胸前           十指相规成角           机簧咬合爆鸣           法宝托掌在手
准星归零待发           唱诵真言口令           冷铸法体成型           随心运化待发
```

1. **【定 势】（起手立桩）**：双臂自然平放胸前，准望匣游标静止，立于方圆界内，起手立定。
2. **【结 印】（十指相规）**：双手靠拢互锁，十指弯折相规成角，唱诵口令（8秒窗口）。双手垂落可【收势】无惩罚取消。
3. **【印 成】（法体凝铸）**：手印合槽瞬间，扣除自身【度力】进 CD，机簧咬合爆鸣，法宝凝成瞬态，1 帧内自动进入运法。
4. **【运 法】（操持在手）**：法宝在手操持运化：
   * **荧惑火核**：火核在右掌心反向自转，托掌瞄准，挥手【出手】掷出；
   * **天宪雷剑**：虚空凝成长剑，持剑指天，朝向位置降下天雷；
   * **定规障**：正方玄铜格栅浮游护身，吸收伤害直至【障破】；
   * **墨线牵引**：拉拽机关或残机偶。

# 5. 第五篇：战斗外墨规画符系统设计 (GlyphSystem - P2)

### 5.1 世界观哲学：工匠墨笔补天地残缺
古代天工司先贤训戒：“规以画圆，矩以作方，墨斗定直，水准平夷。”  
在《考工律度》中，画符绝非道士念咒降妖，而是勘律使拔出**【墨规笔】**，以朱砂磁墨在青铜光栅画板上勾勒严谨的几何图案，**修复失度大地上残损的机关零件**：
* **工匠凝神，独占其志**：执笔如操千斤之重，工匠作画不可分心挥拳出招；
* **破禁启机**：补齐神庙石门缺损的圆规或方矩，校正卡扣，大门轰然开启；
* **冷铸护身拓片**：在安全区调息凝墨，冷铸一枚一次性【金石护身拓片】，战时捏碎提供爆发保护。

### 5.2 程序架构硬边界（严格防误触）
1. **抓笔独占（`ExclusiveInputBlocked = true`）**：
   * 玩家自准望匣侧套拔出墨规笔瞬间，系统物理级拦截双手结印、火核握持发射、右手掌风平切折步；
   * 彻底杜绝画线动作被底层骨骼误判为攻击或移动。
2. **放笔交还输入**：收起或松开墨规笔，解除输入独占，平滑恢复常规行走与战斗基线。
3. **$P 点云识别算法**：
   * 笔尖轨迹投影于青铜画板局部二维平面；
   * 沿笔迹重采样为 32 个均匀特征点，与规印（正圆）、矩印（折角）模板进行点云欧氏距离匹配；
   * 具备高容错率，不设倒计时压迫玩家，支持慢画、悬停观察与撤销重画。

# 7. 第七篇：特色首领【太仪·负衡偶】深度设计案 (Boss Design)

* **外形**：高 2.8 米，右臂拖着 4 米长的青铜天平大秤杆，末端悬挂八棱玄石秤砣；胸腔为三层逆转青铜浑天仪心。
* **招式一【负衡垂地】（考闪避）**：秤砣甩到杆末端，杠杆力道放大数十倍，地面投影宽幅红带，蓄力 3.0 秒。玩家向侧面使出【折步】躲开。
* **招式后摇与卡死机制（核心弱点）**：秤杆过于沉重，抡砸在地的惯性极大，砸空后秤杆深深陷进石缝拔不出来！负衡偶被杠杆反作用力带倒，机体受热发烫，**彻底瘫痪整整 9~10 秒**！
* **招式二【规尺飞射】（考格挡）**：左臂卡尺爪射出 2 枚旋转飞片（每枚 30 伤害）。玩家双手抱拳撑【定规障】吸收。
* **战术教学**：引导玩家在首领攻击前摇时提前搓好火核握在掌心（运法），首领一砸地瘫痪，直接甩手【出手】砸其胸膛发光核心打出 200% 暴击！

# 8. 第八篇：第一切片全流程详细设计案 (Playable Slice: 12~15 Mins)

1. **破败神道（新手引导 3 分钟）**：熟悉【定势➔结印➔印成➔运法】四步，学会托举火核击碎封规石靶。
2. **基标长廊（移动进阶 3 分钟）**：学习食指【缩地】跨越断裂深渊，练习右手平切【折步】规避地面落石。
3. **破禁石门（画符解谜 2 分钟）**：拔出【墨规笔】，在石门画板上补全残缺规印（正圆），石门轰鸣开启。
4. **前庭遭遇（小怪实战 3 分钟）**：面对 3 具【残机偶】，练习抱拳撑【定规障】格挡飞片，甩手掷火核击杀。
5. **祭坛决战（首领初见 4 分钟）**：迎战【太仪·负衡偶】，掌握“折步避长杆、铜盾挡飞刃、趁其瘫痪砸核心”的战斗大循环。

# 9. 第九篇：美术视效与音频工程规范 (Art Direction & Audio Guidelines)

* **美术规范**：凿面青灰岩（70% 墙地）、汉白冷玉（立柱神道）、哑光青铜（准望匣/墨规笔/铜铎）、熔核朱砂（火核自发光）。

### 架构原则共识
1. **去中心化架构**：坚决不搞臃肿的上帝类 `GameManager`，维持以 `LinearRpgController` 驱动单人核心战斗调度中枢的高内聚、低耦合架构。
2. **节奏把控**：首领战（太仪·负衡偶）暂缓代码实装，开发资源集中打磨基础小怪（残机偶）的行为树与战斗闭环。
