# 墨规笔的速度、制动与转折笔触

2026-11-26 · GitHub 固定提交源码核查。墨规笔沿用已有的笔画网格与重描去重，并以单个笔墨材质表现干湿。笔速和制动控制粗细、转折和弧长收锋，笔画坐标与板面坐标分别提供飞白和固定纸纹。实现效果见[桌面对照与编译结果](../../Tools/Validation/Evidence/GlyphBrush1126/README.md)。

## GitHub 源码证据

- **libmypaint — 按时间测速度，按距离滤方向，再交给笔刷曲线。** 位移除以事件时间间隔，结合视图缩放得到速度。`speed1` 与 `speed2` 是不同时间常数的低通速度，随后做对数映射。`direction` 是 180° 轴向，折返等价。`direction_angle` 保留 360° 朝向。两种方向都按步进位移平滑。官方 `Marker.myb` 的 `speed1` 曲线调半径和不透明度，`direction` 曲线转动椭圆笔印，具体快慢效果由笔刷预设决定。公开输入表没有加速度或转角强度通道。`stroke` 随归一化行程推进，可映射渐变，也可配置循环。它提供的是笔程进度，未知笔尾的收锋要另外处理。 [输入定义](https://github.com/mypaint/libmypaint/blob/d5a88fbe6649d5ec776bc42ec8c1f4bb29d7fd7f/brushsettings.json#L22-L105) · [速度、方向与笔程实现](https://github.com/mypaint/libmypaint/blob/d5a88fbe6649d5ec776bc42ec8c1f4bb29d7fd7f/mypaint-brush.c#L771-L891) · [Marker 方向](https://github.com/mypaint/mypaint-brushes/blob/08da4a48a4b63f2e0f3303942d7c21da8479ea9f/brushes/ramon/Marker.myb#L68-L90) · [Marker 透明度](https://github.com/mypaint/mypaint-brushes/blob/08da4a48a4b63f2e0f3303942d7c21da8479ea9f/brushes/ramon/Marker.myb#L173-L199) · [Marker 半径](https://github.com/mypaint/mypaint-brushes/blob/08da4a48a4b63f2e0f3303942d7c21da8479ea9f/brushes/ramon/Marker.myb#L236-L260)
- **墨韵 Moyun — 快走变细偏干，按笔程耗墨，沿笔锋留下飞白。** 手绘入口按带时间戳的位移测速度并以固定权重平滑。走得越快，半径越小、干度越高。笔落时重置墨量和随机种子，行进距离扣墨。每段按半径定步距排高斯笔印，并按步距调沉积量。着色器用笔画法向上的一维噪声切断干笔的颜料，形成顺着行笔方向的细空隙。另有预生成的纸纤维与颗粒，颗粒调制最终墨密度。实时洇染则是独立的多轮 GPU 模拟。手绘链没有加速度或转角强度映射，`s.acc` 是触发音符的累计距离，抬笔事件只清除指针状态。 [手绘输入与停笔](https://github.com/axtonliu/moyun/blob/eb488acf811122bb9a574d87fb148ffa42ed4c23/index.html#L905-L943) · [沿段排笔印](https://github.com/axtonliu/moyun/blob/eb488acf811122bb9a574d87fb148ffa42ed4c23/index.html#L482-L495) · [飞白](https://github.com/axtonliu/moyun/blob/eb488acf811122bb9a574d87fb148ffa42ed4c23/index.html#L209-L232) · [纸纹与密度](https://github.com/axtonliu/moyun/blob/eb488acf811122bb9a574d87fb148ffa42ed4c23/index.html#L302-L335) · [流体循环](https://github.com/axtonliu/moyun/blob/eb488acf811122bb9a574d87fb148ffa42ed4c23/index.html#L498-L534)
- **perfect-freehand — 按弧长收锋，用切线处理急转轮廓。** 可读输入压力，也可用点间距除以基准笔宽估压。后者没有时间项，恒定速度下换采样频率也可能改变宽度。收锋用离起点和终点的弧长分别求缓动，取较小倍率乘半径，再拼接两侧轮廓与端帽。相邻切线点积为负的急转分支加圆弧补片，处理的是接缝轮廓。可借鉴弧长和接缝处理。 [模拟压力](https://github.com/steveruizok/perfect-freehand/blob/176e00f2399f4969e1b0965c5921d96a3e50ce9f/packages/perfect-freehand/src/simulatePressure.ts#L15-L28) · [压力与收锋](https://github.com/steveruizok/perfect-freehand/blob/176e00f2399f4969e1b0965c5921d96a3e50ce9f/packages/perfect-freehand/src/getStrokeOutlinePoints.ts#L244-L299) · [急转接缝](https://github.com/steveruizok/perfect-freehand/blob/176e00f2399f4969e1b0965c5921d96a3e50ce9f/packages/perfect-freehand/src/getStrokeOutlinePoints.ts#L303-L347)

## 在 VR 里先验证什么

**本地快照。** `GlyphBoard` 记录超过间距门槛的板面局部坐标和时间，辨符读原二维分笔。`GlyphBrushProfile` 已用带时间的低通速度、带符号的制动量和相邻方向差驱动宽度及湿度，末段收锋距离取决于弧长、尾速和制动。`GlyphStrokeGraphic` 生成带状网格，`GlyphBrushInk` 已用横向笔触坐标、纵向弧长和画板局部颗粒画飞白。 [画板](../../Assets/scripts/logic/Rpg/Glyphs/GlyphBoard.cs) · [笔刷参数](../../Assets/scripts/logic/Rpg/Glyphs/GlyphBrushProfile.cs) · [显示网格](../../Assets/scripts/logic/Rpg/Glyphs/GlyphStrokeGraphic.cs) · [笔墨材质源码](../../Assets/Shaders/GlyphBrushInk.shader)

1. **先调运动映射。** 用实际时间差滤速度。正加速与减速从平滑速度的有符号差分取得，转角从相邻有效切线取得。保留低速加宽加湿与快划偏细偏干，减速只在有足够位移的转折处小幅增墨。低速抖动、短停、失追和另起一笔分别回放，避免把采点稀疏或跨笔间隔当作制动。收锋按末段弧长，限制在短尾段，检查预览延展时旧墨是否可见地反复变宽。
2. **再调纹理。** 保持单材质和画板固定纹理，用干度逐渐显露顺笔的空隙，留下连续可读的墨芯。A 用旧版均宽线，B 用毛笔版，对同一计时轨迹做不同采样密度回放，再在 Quest 画慢直、疾扫、减速直角、急返、小点、抬笔补笔和失追恢复。核对转角连续、末端可见到抬笔点、飞白在双眼和转头时稳定、同一输入的辨符结果一致。以同场景 A/B 记录 CPU 网格更新与 GPU 帧时间。
