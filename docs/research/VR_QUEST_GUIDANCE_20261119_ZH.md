# 首章院落的 VR 任务引导

2026-11-19 · 首章院落选型记录与试玩设置。

建议先做从外门到双盘、再到验腕座这一段。远处分辨下一道门，走近后辨认能碰的部件，手已就位时知道能否松开。这三件事分别需要路口标记、物件提示和操作反馈。光点线适合第一件事，保留为玩家随时可叫出的寻路辅助。

### 当前可试玩的部分

打开 [Chapter01_Courtyard](../../Assets/Scene/Chapter01_Courtyard.unity)，在 Hierarchy 用 `t:CourtyardTaskGuide` 定位组件。为了直接比较效果，测试版默认勾选“探索时显示寻路光点”和“卡住时示范手势”。可以在 Inspector 分别开关。按腕匣请求寻路仍是下文的候选设计。 路线与示范动作按阶段或教学句配置，添加交互点的步骤见[章节配置指南](../guides/CHAPTER_FLOW_ZH.md#为阶段或教学步骤配置光点和手势)。

[观看外门折廊和双盘台的测试视频](../visuals/20261119_courtyard_guidance/首章_光点寻路与手势示范.mp4)。视频取自独立 Unity 桌面 Play 的玩家眼高机位，角色移动、捏转由测试输入驱动，语音按录制时实际播放的原旁白片段与进度合成。片末将铜耳处的原画面放大，以半速回看。[白色示范手近景](../visuals/20261119_courtyard_guidance/首章_白色示范手_铜耳近景.jpg)

- **路线**使用场景已有的 22 个相邻导航点，从试炼间经外门、折廊、双盘台，接到校验座、量水道和终点。8 个阶段分别指定终点。玩家脚前显示一串间隔约 36 厘米的金色光点，每颗带柔和光晕，错开明暗并在地面上方上下轻浮约 1.5 厘米（单侧振幅），经过转角分段连接，战斗和由 UI 接管输入时收起。地上的战斗落点照常处理选点和瞬移。[寻路接线](../../Assets/scripts/ui/Rpg/CourtyardTaskGuide.cs) · [光点绘制](../../Assets/scripts/ui/Rpg/QuestTrailDots.cs)
- **机关示范**使用项目现有的 Meta OpenXR 右手模型与捏合姿势，示范手采用不透明度 38% 的半透明淡白材质，铜耳和盘面刻线可透过手掌看见。探索中走到交互部件水平距离 1.25 米内，当前旁白和补充语音播放结束后，连续等待 7 秒触发。转盘抓对铜耳会收起示范，取叶和入匣分别由实际握持及槽口接触状态控制。一次动画 2.8 秒，仍需帮助时隔 5 秒再演。触发距离、首次等待、演示时长和重复间隔都在对应阶段或教学句的「视觉引导 → 手势提示」中设置。[手势呈现](../../Assets/scripts/ui/Rpg/QuestGestureHand.cs) · [机关判定](../../Assets/scripts/logic/Rpg/OpeningLeafPuzzle.cs)
- **声音**沿用首章旁白、字幕、停滞提示和腕匣重听。首段 18 秒的额外语音提示仍由原有条件累计。手势只提供画面，遇到语音开始即收起。外门到折廊的地面提示从阶段生效就可见，能在进入下一段旁白触发区前指路。[首章语音与流程](../../Assets/scripts/logic/Rpg/OpeningTrialChapter.cs)

## 可借鉴的 VR 研究和游戏做法

| 一手来源 | 对首章的启发和适用边界 |
|---|---|
| Varshney 等人让 42 名参与者在房间尺度 VR 迷宫中完成 1008 次寻路。在限时、低能见度且需要重新选路的条件下，方向箭头的寻路表现最好，其次为小地图，再次为指南针。[作者论文与摘要](https://arxiv.org/abs/2603.17238) | 在有分岔、需要马上作决定的地方，直接显示“穿眼前哪一道门”。这项实验没有比较院落地标和整程光点线，也没有测探索乐趣。 |
| HiveFive360 对照了三种把注意力引向视野外目标的提示，包括以小群移动物体带动转头。作者报告其能有效找到目标，实验关注完成时间、临场感和任务负荷。[作者项目页](https://visvar.github.io/pub/kerga%C3%9Fner2024hivefive360.html) | 可把动势缩到一小段，在当前可见的门柱旁起亮，沿转角移向下一枚记号。适合提醒“看那边”。穿过多间房仍需要可走路线。 |
| 微软在 HoloLens 2 的 Hand Coach 中用贴近交互物的手影演示按、抓和转动。玩家一段时间没有做出动作才出现，语音和示范依次给出。[微软的设计说明与动图](https://learn.microsoft.com/en-us/windows/mixed-reality/design/hand-coach) | 双盘前可以演示手指捏住铜耳并转一小段。它是混合现实产品实践，首章裸手与手柄的可读性仍应分别验证。 |
| 《Moss》开发团队说明，玩家解谜卡住时，Quill 会用手势给线索。[Polyarc 开发者访谈](https://operationrainfall.com/2021/01/27/vr-interview-polyarc-games-talks-about-moss-part-1/) | 如果处理侧廊工役，可以让他在路口望向或指向门口。角色走出视野后，门上的方框仍能让玩家认回方向。此项可排在器物反馈之后。 |

## 第一版的玩家体验

| 场合 | 默认看到什么 | 需要帮助时 |
|---|---|---|
| 出外门，去框下的双盘石台 | 出门即看见下一道可通行廊口上的开口方框，开口朝行进方向。转过去才看到双盘上方呼应的方框。腕匣当前目标写“穿过方框门，到石台前”。路标从阶段生效开始可见。 | 玩家点腕匣“指路”，最近的门柱上依次亮起两三枚短尺刻，越过转角后接下一段。背对路口时从视野侧边的临近位置给一次转向提示，转进来就收起。门旁可配一次空间铜响，静音也看得懂。 |
| 在双盘前 | 先让人认出参照用的石刻，再用一道贴着铜耳的浅亮边指出能捏的位置。手指到位时反馈接触，转盘仍由玩家观察和对齐。 | 尝试后仍没带动盘，再演一次“捏住铜耳、转一点、松开”。演示后淡出，保留对齐谜题。 |
| 拿到铜叶，装到准望匣 | 提示从尾环切到左腕实际空槽。槽口有开口轮廓，叶片导向头有对应缺口。进入有效接触时缺口合拢，并出现“松手”提示，吸合成功后短响、轮廓收起。 | 插偏时轮廓维持开口；重试仍困难才在腕旁演一次送入方向。持叶全过程能直接看到反馈，无须放下铜叶操作腕部菜单。 |
| 装妥后，去验腕再沿渠前进 | 验腕阶段只亮门旁校验座的腕形凹位。腕匣通过判定、闸门开启后，提示才交给水渠入口。沿渠用水尺与栏杆辨方向，到测候台完成当前章节。 | 跨房或从检查点恢复时可请求当前这一步的短线。完成首章后清除主线提示，三座可探索的工坊仍可自由进入。[院落路线与终点](../visuals/20261119_courtyard_scene/场景验收.md) |

## 光点线如何接入

1. 首版只给外门、转廊、双盘台和验腕座配置可走的中途点。每次指向下一道实际可通过的门，途经台阶时沿踏面铺设，关闭的闸门先指向当前可操作机关。终点到达或阶段推进就撤去路线。希望持续跟随的玩家可以选择常显辅助。
2. 章节继续负责当前阶段和操作，机关继续判定接触、入匣和验腕。场景提示读取当前步骤、路口锚点、目标器物及它已有的判定结果，决定显示什么。有效入槽状态若需给 UI 使用，应由机关公开只读结果，避免重新计算一套松手距离。两套首章场景共用进度 ID，各场景各自绑定空间锚点。
3. 首版用烘焙环境明暗、共用材质和一段可复用的短线网格；仅在求助、经过路口或步骤改变时更新路线。形状和明暗共同传意，战斗时让出地面给落点和危险区。玩家转头自主，额外空间音、震动分别作为补充。Quest/PICO 的可读性与开销均需实测。

## 怎样决定光点线要不要常开

选“出外门找双盘 → 转动 → 取叶入匣 → 找验腕座”。用相同物件反馈和旁白，A 组全程看光点线，B 组默认只看门标、需要时点指路。首轮用首次进入院落的玩家分组，固定起点和存档，在同款头显上对照。另测一次关声和一次从转廊检查点恢复。分三段记录用时及出错的位置。

- 从目标切换到走进正确廊口，记录走错门和主动叫线次数。
- 从抵达双盘到第一次捏住有效铜耳，区分碰错物件与手势未被识别。
- 从拿到铜叶到首次有效接触、再到成功落座，分别记录插偏与有效接触后松手失败。

同时记下是否需要旁人开口、是否一直低头看地、是否认得返程，在同场同机位记录提示开启前后的 CPU/GPU 帧时和掉帧。若 B 组主要耗在某个岔口，先补那个岔口的可见方向；若 A、B 都耗在槽口，优先修槽口反馈和识别。以上为验证设计，本次只核对工程、已有实景记录与公开来源。
