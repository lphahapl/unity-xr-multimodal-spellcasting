# 《考工律度》战斗中的技能列表与冷却显示

初查 2026 年 11 月 19 日，11 月 20 日补查市售游戏的技能选择、战斗状态与本项目源码。下文保留当时提出的左腕方案。随后按玩家要求，工程接入了**右手抬掌快览**和**左腕准望匣的独立「术法状态」页**，后者可跟随或固定。当前操作以[腕匣指南](../guides/WRIST_MENU_INTERACTION_DESIGN_ZH.md#查看当前术法状态)为准，头显实测仍待进行。

建议在现有左腕准望匣上做一块**抬腕即读的术式投影**。按朱砂扣仍可查完整术式和结印方法。交战中只需扫一眼固定位置的几个大图形，持剑或持球时也能看。优先用普通护盾、火球、龙火做第一轮，它们分别能暴露共用冷却、手部占用、停喷才开始倒计时三种容易误读的问题。

## 本项目采用三层信息，不增加一次选技能操作

1. **正常交战：看敌人与手中术式。** 手中火球、雷光剑或喷流表达当前动作阶段。没有持物时也不要求玩家打开列表才能结印。只有玩家明确尝试失败，才给一条短原因；不要每个冷却完成都播音。
2. **想查可用招式：抬左腕看只读快览。** 在准望匣旁固定摆少量图标，先试三个，必要时对照四个；这是可读性试验数量，不是携带技能上限。顺序固定，不按剩余 CD 自动重排。图标回答“就绪／还需几秒／度力不足／持用中”，不接受点击施放。腕部朝向加头部朝向可作为试验唤出条件，无须眼动追踪，也不要要求张掌或捏合这种会干扰施法的手势。
3. **想查全套技能和教学：点朱砂扣。** 完整列表保留技能名与资格分类，点选后再看印图、口令、消耗和基础 CD。长时间看教学时沿用可拉出并固定在空间中的卡片，让手臂放下。该入口继续遵守现有输入优先级，不因新增快览而放宽持物时的菜单操作。

例如，腕边的同一排固定位置可以读作：`[火球：持球]  [护盾：2秒]  [龙火：度力不足]`。这是文意示意，具体造型仍应使用本项目的纹样与图标，不能把一排长文字当成最终战斗 UI。

微软的手部菜单设计建议少量控件、短交互，长交互改为空间或身体定位；也提醒单凭掌心朝上容易误唤出。这些是 HoloLens 2 的设计经验，仅借用原则，不直接套用其按钮数量、13 厘米位置或系统按钮限制到 Quest/PICO。[Microsoft Hand menu](https://learn.microsoft.com/en-us/windows/mixed-reality/design/hand-menu)

| 方案 | 本项目取舍 |
|---|---|
| 屏幕边缘常驻完整技能栏 | 暂不作为默认。会持续占用视觉空间；若抬腕测试影响躲闪，再给玩家可选的少量图标 HUD，比较实际表现。 |
| 战斗中打开大轮盘、逐项选招再施法 | 暂不采用。结印和口令已经承担选招；裸手轮盘还需新的确认动作。未来手柄快捷施法模式可以单独评估。 |
| 只靠手中物发光或提示音 | 作为补充。它解释不了没有拿在手里的另一招还剩多久，也不能独立表达所有资格、度力与占用原因。 |
| 每次抬腕自动展开完整列表 | 不采用。格挡、结印等动作也会抬手，完整列表需要明确开启；只读快览才适合快速出现与收起。 |

## 准望匣具体显示什么

| 玩家正在做什么 | 建议看到的内容 |
|---|---|
| 战前想知道自己会什么 | 按朱砂扣进入「术式」，默认列出永久解锁的术和当前章节可试用的术，试用项带「试用」。再翻到「已了解」查看尚待解锁的课程；隐藏术沿用发现条件。点术名才展开印图、口令、度力消耗和基础冷却。 |
| 敌人逼近，快速看一眼 | 左腕朝向自己时，在气血、度力双尺旁展开一小块朝向玩家的投影。原型先摆三个固定位置，火焰、盾、龙首各有轮廓；放下腕就收起。各场景按实际许可显示，放不开的术仍能在完整列表查看。首版用固定显示顺序，避免每次施法后图标换位。 |
| 想判断哪一招值得等 | 可起手的术显示完整亮纹；冷却中的术保留轮廓，外圈逐渐补全，旁边显示向上取整的剩余秒数。度力不足显示缺口水滴，展开可读「需 20／现有 12」等实际数值。冷却结束而度力仍不足时保留缺口。形状和短词都能传递状态。 |
| 右手持剑、持球或手在嘴边 | 抬腕查看只读，与点扣、捏选和施法彼此独立。优先让手中物或喷流表现当前动作。离腕时若刚才尝试护盾失败，可在腕边提示「护盾 · 还需 2 秒」；若测试发现它常在视野外，再试一次短促、可关闭的就绪音。裸手追踪的版本也能得到完整反馈。 |

顶面已有两排十格，玩家侧圆盘还有五字铭文和方口解谜接口。在原型里把图形投在匣边，可以直接利用原有腕部定位，也给字号、图标间距和朝向留出调节余地。[腕匣当前操作与实景](../guides/WRIST_MENU_INTERACTION_DESIGN_ZH.md) · [现有双尺外观](../visuals/20261112_model_display/准望匣双尺刻格.jpg)

## 最小真机对照

用同一段试炼、同一存档，在 Quest 上对照「点扣看教学卡」和「只读抬腕快览」。让玩家分别在敌人起手时找可用护盾、持球等召球冷却、喷火后判断何时能再喷，并在度力不足时说明原因。记录从提示到正确回答的时间、误判次数、漏躲次数和误开菜单次数，同时询问哪个图标需要凑近才能认出。两种顺序交换再测。若抬腕缩短查找时间却增加漏躲，先对最常错过的一项试局部提示，再决定是否扩大显示。图标个数、尺寸、提示音和是否能看清均待头显实测。

另加右手持雷光剑、左右手短暂遮挡、连续结印、坐姿与追踪恢复几个条件。验收时必须确认快览没有取消结印、吞掉口令、误开主菜单；追踪丢失时隐藏无法可靠定位的腕边显示，恢复后重读状态。若腕边方案查阅代价仍高，再与可关闭的少量 HUD 图标对照，保留结果更好的选择，不预先宣称沉浸式布局一定更易用。

## 调研范围与证据限制

本次优先核查开发者日志、游戏官方页面、工程师本人项目说明及本地源码；Roboquest 冷却位置明确标注为 PS VR2 评测者的第一手观察。浏览器工具库存只有内置浏览器和 MCP Apps，没有暴露用户远程调试 Chrome 的连接，因而使用 web 工具读取公开页面；这不代表用户 Chrome 或其 IPv6 调试端点没有运行。没有操作其他制作标签页。未对市售游戏当前所有平台版本逐一复现，也没有测量本项目的头显可读性和性能。
