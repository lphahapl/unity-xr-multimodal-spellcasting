# 技能测试场景使用说明

2026-10-29。首版实现目录 `Assets/SealCombat`。原录制场景、识别场景和子丑寅模板继续独立使用。

同日已完成配置架构升级，最新入口见 [项目 README](../README.md)。当前由 `SkillCatalog` 管理技能列表与取消口令，`SkillTestView` 管理显示，效果数值与预置体在技能引用的效果资产中配置。下文默认操作仍适用。

## 打开和运行

Unity 菜单 **Tools → NarutoVR → 技能 → 打开技能测试场景**，或直接打开 `Assets/SealCombat/Scenes/SkillTest.unity`。连接 Steam Link 后按 Play，放下控制器。场景沿用已经能工作的 OpenXR / XR Hands 实际骨骼来源。进入场景不会自动录制骨骼到磁盘。

| 测试技能 | 条件 | 结果 |
|---|---|---|
| 子印加持 | 子印达到原模板分数、覆盖率、保持时间和消歧要求 | 立即得到 100 点护盾，默认持续 10 秒 |
| 护体咒加持 | 检测到“护体咒” | 立即得到同一护盾；再次成功使用刷新到 100，不相加 |
| 火球术 | “火球术”与寅印在 8 秒内匹配，先后不限 | 立即在当前右手腕前上方生成火球；向前轻推发射 |

每个测试技能默认冷却 3 秒。丑印参与评分和消歧，但当前没有绑定技能。当前配方只支持一个印；十二印序列、武器、领域、环境遮罩和移动范围限制不包含在这次可运行版本内。

## 不用腾手点击的测试方法

先在电脑操作台点击 **5秒后模拟“火球术”**，或按 **F7**，再戴好头显摆寅印。倒计时结束会注入一个明确标注“模拟”的口令事件。**F6** 同样测试“护体咒”。这些按钮不代表语音模型识别成功。

真实语音服务的安装、麦克风选择、启动与停止见 [中文口令说明](SKILL_VOICE_SETUP_ZH.md)。当服务没有启动时，纯结印和模拟按钮仍可用。使用真实麦克风时，先观察面板的服务状态；Windows 默认麦克风不一定是 Steam Link 麦克风。

## 火球怎么发射

生成后留出至少 0.25 秒准备时间，手向头显正前方轻推至少约 12 厘米，动作持续 0.15～0.6 秒。火球从手上朝头显中央“＋”瞄准点飞行；准星碰到场景物体时，以该表面为目标，否则朝 30 米处飞。

同时检查手在世界中的前移和相对头部的前移，避免仅后仰或整个人向前走就发射。此处数值是初始参数，硬件手感仍需实际调整。火球命中训练靶造成 25 点伤害；靶子 100 点生命，击破后约 2 秒恢复。飞行球有连续球形碰撞检查，撞墙会结束。

手追踪丢失时持握球立即隐藏，持续超过 0.5 秒会消散；短暂恢复后重新等待准备时间。默认持握最长 10 秒、飞行最长 4 秒。同一时间只允许一个持握火球，已发射的球不会占住手部槽位。

## 取消与改错

- 说 **“取消施法”**；或张开双手、双腕相距至少 35 厘米，保持约 0.5 秒；电脑也可按 **Esc**。
- 如果正在等待“口令对应的印”，先取消本次待匹配输入；否则收起持握火球，再次取消可结束已有护盾。
- 取消会清除旧口令、旧手印证据与缓存。退出旧印至少 0.15 秒后重新结印，避免旧姿势立即重放。
- 一直保持同一个印只算一次；追踪丢失和恢复也不会把同一印当成第二次。
- 已发射火球的伤害无法撤回。取消不会删除已发射火球；退出播放、禁用组件和暂停会统一清理临时效果。
- 没说出有效口令就不会增加候选；错印不会释放该组合技能。口令已确认但 8 秒内没匹配到印，会自动超时。冷却中输入被消费，不会在冷却结束后补发。

## 面板与中文 Inspector

“技能训练台”物体上的 `SkillTestController`、`SkillEffects`、`SkillVoiceReceiver`、`SkillTestView` 均提供中文字段。技能规则从控制器当前引用的 `SkillCatalog` 进入相应技能及效果资产配置，避免改到旧 `Profiles` 副本。

头显面板显示骨骼缓存帧数/时长、等待技能和倒计时、语音服务状态、护盾点数和剩余时间、成功激活/命中次数，以及当前配方涉及的印分数和覆盖率（默认子、寅）。显示行数在 View 配置。分数是模板相似度，并非经过概率校准的统计置信度。

组合技能默认仅把单印阈值降低 **5 个百分点**，且不低于 65 分。例如原寅印 80 分，则组合门槛 75 分；覆盖率、必需特征、保持时间及与其他印至少 5 分的差距仍要满足。不会修改原始寅印或子印 SO；此前对子印中指特征的调整仍保留。

等待组合印时，控制台约每 2 秒打印一次有效门槛和特征明细：缺失特征、覆盖率、各特征得分等。明细中的基础模板门槛用于对照，首行的“本次有效阈值”才是组合判定值。失败也可能是保持不足或和其他印无法区分，不能只看总分。

## 代码路径

`SealLab` 每次新骨骼快照 → `SkillTestController` → `SkillMatchEngine` → `SkillEffects`。语音则由本机 sherpa-onnx 服务 → `SkillVoiceReceiver` → 同一匹配器。

匹配器保存最多 10 秒、640 个槽位的骨骼深拷贝和不可变评分事实，默认 60 Hz 采样上限。另维护完成保持的单印证据，因此收到口令时不必重跑全部骨骼特征算法；先印后咒也能按组合阈值匹配。超过 2 秒才送到的语音结果拒收；8 秒窗口加 2 秒延迟预算覆盖在缓存内。所有时间基于同一单调实时时钟。

技能 SO 在进入播放时成为匹配配方；修改触发配方后停止再运行。效果资产管理数值、轻推参数与视觉，执行器保留玩家锚点和碰撞层。增加口令时，在技能资产填写口令与声学 tokens、加入目录，再用“技能配置 → 导出当前场景语音配置”导出 JSON 并重启服务。接收白名单与调试按钮自动读取目录，无需修改三处源码。

## 验证入口与范围

菜单 **Tools → NarutoVR → 技能 → 创建并检查技能测试场景** 会验证场景绑定和运行核心回归，不覆盖已存在的场景自定义内容。`SkillCoreChecks` 在编辑模式运行；`SkillEffectChecks` 在播放模式使用远离场景的临时对象，测试结束清理。

`Logs/skill-test-result.json` 是最近一次操作结果，`hardwareTested=false` 表示自动检查没有替代真人戴头显验收。中文语音的合成 WAV 测试仅验证模型与链路，不能报告为实际玩家的识别准确率。
