# 四向操作、反馈与骨骼投掷

2026-10-31补充：RPG火球现支持原有松手投掷、后拉前送评分发射、主动伸手保持发射。新辅助方式不强求Open边沿，但必须先确认握持。评分、硬条件、优先级、自动JSONL及调试字段见[当前投掷说明](SCORED_THROW_DIAGNOSTICS_ZH.md)。下文Neutral不能发射的描述仅指旧松手路径。

更新：2026-10-30。适用 `Assets/SealCombat/Scenes/LinearRpgTest.unity`。Quest → Steam Link → SteamVR OpenXR；骨骼输入仍经跨平台快照，未新增厂商原生依赖。

## 操作

| 操作 | 输入 | 提示 |
| --- | --- | --- |
| 四向选点 | 左食指伸直，其余三指收拢，稳定0.2秒后从手的起点平移5厘米 | 选中音、蓝色路径流光、落点圈、脚下位置圈 |
| 确认移动 | 保持所选方向约0.65秒 | 金色进度圈填满，瞬移成功音和扩散圈；左手回起点后再选 |
| 独立闪避 | 右手张掌，10厘米四向短划；无需左手指向 | 成功音和当前位置扩散圈，失败音及HUD原因；0.8米/1.2秒CD |
| 投掷火球 | 寅印与“火球术”完成配方，右手生成；分开双手，握拳或捏住，甩手并松开 | 持球握持状态、准备/发射/命中音和原有火球特效 |
| 取消 | 双腕保持可见，放低并保持0.4秒；或“取消施法” | 取消音和紫色扩散圈。保留已生效护盾、飞行火球，不退款 |

节点方向以进入导航时的头部水平朝向固定；转头观察不会中途改向。闪避选最近的四个主轴方向，斜划按优势轴，尚未做八向闪避。

## 输入优先级

1. 暂停、死亡、无效或过期追踪拒绝对应动作；丢追踪不等于取消或松手。
2. 已有右手投掷球占用全部右手动作，包括尚未握住和准备期间；左手导航仍可用。发射后收手须稳定0.18秒才重新准备闪避，同一甩手不能附带闪避。
3. 双腕距离不大于0.26米进入结印保护，撤销导航并禁止右掌闪避；两腕至少分开0.34米、都新鲜同步，并在3.5厘米范围内稳定0.18秒才解除。保护期间手丢失不会解锁；分手运动不能直接变成闪避。
4. 左食指导航与空手右掌闪避分别工作。无此前结印保护时，左手不可见也允许右手独立闪避。

结印保护是空间意图启发式，不是新的印分类器：它降低贴合/穿插时把右掌看成Open造成的误触，但手腕相距较远的印仍可能需要真机调参。HUD明确显示保护状态。原十二印的权重、模板和录制格式未更改。

## 投掷算法与配置

`HandThrowState` 只接收有时间戳的握持状态、手腕和头部位置，返回发射速度向量；`SkillEffects` 负责持球和飞行实体。

- 当前 RPG 握拳仍使用官方四指 Closed；松拳开启“允许三指张开松拳”：至少三指 Open，剩余一指只能 Open/Neutral，且四指特征全部有效。闪避仍要求四指 Open，不随投掷放宽。捏合用有效拇食指尖距离：小于等于3厘米握住、大于等于4厘米松开，中间为迟滞区。配置在 `效果_fireball.asset`，不是所有场景的全局阈值。
- 先确认握持0.04秒；第一次从Closed进入Neutral或Open时冻结轨迹，有效松手确认0.015秒后提交；最多等待0.26秒。仅Neutral、重新握紧、无效追踪均不发射。
- 对松手前0.12秒轨迹排除尾段0.01秒，使用时间加权最小二乘与两轮Huber重加权估计速度。当前最低0.45米/秒、最低手相对身体位移3.5厘米（2026-10-31从0.65米/秒、5.5厘米下调）。残差、跳变、长观测间隔、重复样本和丢失特征保护不变。[算法、导航融合评分和诊断录制](THROW_DIRECTION_AND_NAV_SCORING_ZH.md)记录算法依据。
- 静止松手仍持球，可重新握住投掷；不是物理掉落。火球默认匀速直线飞行，无重力弧线；技能速度决定飞行速度，手速只决定是否满足释放门槛和朝向。
- 已持火球优先接收投掷输入；结印结束时残留的双腕距离保护不再每帧清空它的轨迹。持球期间仍阻断右手闪避，死亡/暂停/UI接管仍禁止释放。只有右手恢复有效追踪及握持证据才能投掷，左手移出视野不应永久卡住已持球。
- 球的位置为腕关节位置＋腕旋转×局部偏移，默认`(0,0.025,0.065)`米。不是头部旋转×偏移，也不从胸口生成。
- `ProjectileEffectDefinition.releaseMode` 支持旧版前推和新版握持投掷。激活时复制配置，运行时修改SO不改变已生成火球。旧展示场景未切换。

Inspector中 `RpgLocomotionController/手势参数` 调整选点、短划和结印保护；`RpgInteractionFeedback` 调整提示音、音量和地面表现；`Configuration/LinearRpg/效果_fireball.asset` 调整投掷参数。字段使用中文标题和名称。

## 模块职责

- `OfficialHandPoseDetector`：官方单指阈值和状态确认；输出指向、张掌、握拳及有效性。
- `LinearRpgController`：快照转世界坐标、握持输入适配、玩家状态和技能优先级。
- `RpgGestureState`：纯选点/闪避/保护/动作重备状态；重复渲染帧不增加保持时间。
- `RpgLocomotionController`：节点、实际地面、身体占位、沿途碰撞和Rig平移。
- `RpgInteractionFeedback`：只读表现和提示音。复用线渲染器、一次性生成非语言提示音；可替换AudioClip。监听异常隔离，不得打断玩法结算。
- `HandThrowState`：握持、释放边沿及短时轨迹；`SkillEffects`执行实际生成和发射。

## 语音与串流

Windows“录制”中启用 `Steam Streaming Microphone`。当前服务通过显式设备号打开该输入，并已实际收到“火球术”。重启串流后若采集断开，重新枚举设备再启动，设备号不保证不变：

```powershell
Tools/SkillVoice/.venv/Scripts/python.exe Tools/SkillVoice/skill_voice.py --list-devices
Tools/SkillVoice/Stop.ps1
Tools/SkillVoice/Start.ps1 -Device <当前Steam麦克风序号> -Config Assets/SealCombat/Configuration/LinearRpg/skill-voice-config.json
```

HUD“中文口令识别中（本机）”仅证明连接就绪；实际口令日志验证声音链路。识别到咒语不等于技能可激活，仍检查手印、解锁、MP与CD。

## 验收范围

自动检查包括四向/斜向选择、默认驻留、独立右掌、结印距离迟滞、重复/异步/丢失样本、分手与投掷后防连发、原点平移、握拳/捏合投掷方向、静止松手和身体移动拒绝。Play检查经过实际效果LateUpdate与发射路径，实际场景检查路径/落点/进度和提示音调用。

结果及范围见[本轮验收](DIRECTIONAL_INTERACTION_QA_2026-10-30_ZH.md)，原始报告在 `Logs/direction-feedback`。测试使用合成手部轨迹，不等于真机识别准确率、实际听到提示音或舒适性已经通过。建议先各方向做10次，之后交替结印和投掷，记录误触与漏触，再调整阈值。
