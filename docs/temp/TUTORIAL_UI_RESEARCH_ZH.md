## 方案比较与推荐（建议）
| 形态 | 优点 | 风险与用途 |
|---|---|---|
| 持续随头眼前面板 | 易找、不必抬手 | 遮挡战场、持续头锁可能不适；仅留短提示，不承载长文 |
| 腕部召出后世界固定速查卡 | 阅读不依赖持续抬腕，减轻疲劳 | 入口可能撞移动、闪避、持球；仅少量内容，可关闭或重新定位 |
| 固定教学台 | 双手自由，易隔离实战输入 | 需前往；最适合分步示范与安全练习 |

**更新建议：先做腕饰三入口和一张独立速查卡，固定教学台作为安全练习补充。** 握拳抬腕是新的召出目标，仍需注意条件与输入归属防误开；菜单从腕旁展开后固定已在首版实现。面板位置、字号及停留阈值均待真机标定。

## 玩家流程与输入所有权（建议）
流程：进入安全教学区→明确打开→选技能→看示范→按需听口令→开始练习→看反馈/重试→退出。

拟定仲裁区分：Combat（含只读查阅卡）、UIInteraction、Demo/Practice、Rearm；面板可见不等于取得输入所有权。
- 入口只在安全、无导航、无持球、无结印保护时受理；否则拒绝，不排队后开。不抢左指导航、右掌闪避、持球松开投掷。
- 只读卡不抢战斗输入；点按/拖动时由 UI 消费相应输入；Practice 只产练习反馈，不派发战斗效果。单腕放低关闭小入口；双手放低可取消本轮练习，面板可继续显示，另有显式退出。
- 进入时清理待处理输入；不得覆写 RPG 已占用的阻断/激活回调，应增加可组合的仲裁层。
- 退出、失焦或追踪中断时撤销教学所有权、清队列；恢复追踪且双手回中性、旧握持/手势释放后才重新武装，禁止残留输入立即闪避或施法。

`CancelInputOnly()` 不撤销已提交效果，因此安全练习不能仅靠“进去后取消”。

## 教学卡内容（建议）
- **结印**：名称、用途、所需手型/朝向、分步幽灵手、关键误差；示范手与实测骨骼分色。
- **画符**：仅标“预览/未实现”，可示意起点、方向、笔序；预留教学适配接口，不显示虚构识别分。
- **口令**：准确文本、适用技能、是否需同时结印、示范播放键、当前监听状态。
- 追踪有效性、真实识别分（若接口提供）、课程进度分列。缺骨骼提示“追踪不足”，不能算玩家做错。

## 音频与自识别防护（建议）
短音效表达悬停、按下、成功、失败，配视觉反馈；中文示范音用于发音教学，按需播放，不自动循环，不能等同识别成功。

播放前取得音频独占令牌：在 ASR 匹配与取消口令处理**之前**关闸，取消旧会话并清延迟队列；播放及尾音期停止接收命令。结束后清缓存，以新会话代号恢复监听，丢弃旧代号的迟到结果，再提示“请跟读”。尾音窗须按设备/扬声器标定，不能依赖耳机不漏音。

现有 `ProcessVoice()` 先处理取消口令，再查 `VoiceInputBlocked`，故仅设该回调不足。课程取消须仍有非语音路径。

## 平台边界与待确认项
Quest 可基于现有 Meta/OpenXR/XR Hands 链评估，勿为菜单单独混入 XRI。PICO 的手骨骼、追踪有效性、音频路由及 ASR 暂停/清缓存能力尚待核实；通过平台适配层隔离，不能宣称接口等价。“注视”先指头部朝向，不假定眼动。

当前沿用 Quest 3 / Steam Link 优先、PICO 后续的项目决定。首期建议独立安全教学区，通过场景交互打开；不依赖暂停来隔离战斗效果。实施前由开发侧核对 sherpa-onnx 服务的停止监听、清缓存及会话边界。中文示范音来源和音色在制作前再选定。

**新首期目标**：腕饰入口＋独立结印/口令卡；画符仅标明预览。详细点按稳定、关闭和输入仲裁方案见腕部文档；固定教学台将复用同一套内容。腕饰首版已实施，验收范围见腕部文档第 7 节。
