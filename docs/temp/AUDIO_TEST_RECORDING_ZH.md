# 真人口令测试录音清单

优先使用实际游玩时的麦克风。推荐 WAV、单声道、16-bit PCM，16 kHz 或 48 kHz；不需要另装录音软件，只要保留原始录音。不要额外降噪、变声或裁掉词尾。不同麦克风分目录保存，并注明来源。

| 建议文件名 | 内容 | 已知预期 |
|---|---|---|
| 护体咒.wav | 正常说3次、慢说1次、快说1次；间隔约2秒 | 5次护体咒 |
| 火球术.wav | 同上 | 5次火球术 |
| 取消施法.wav | 同上 | 5次取消施法 |
| 连续口令.wav | 护体咒→火球术→取消施法→火球术→护体咒；间隔约1秒 | 顺序一致，共5次 |
| 易混淆词.wav | 护体、火球、取消、释放、火球树、护体罩；各两次 | 希望不触发；用于测漏词/近音误报 |
| 日常说话.wav | 随意说约30秒，不含三个完整口令 | 不触发 |
| 环境声.wav | 不说话约30秒，保留实际风扇/键盘等背景 | 不触发 |
| 否定句.wav（可选） | 不要释放火球术；我刚才说了护体咒；你说取消施法了吗 | 当前KWS可能命中；作为语义边界单列，不混入纯声学误报 |

提供目录路径和麦克风名称即可。原文件保留，分析用副本或只读加载。当前工具可直接读取单/双声道 PCM16 WAV，双声道会平均成单声道；其他格式先另存转换副本。

收到录音后先在当前固定模型和阈值上测试，逐条记录预期口令、实际口令、漏检/重复/近音误报和发生位置。短录音不能据此宣称长期误报率或所有玩家准确率。需要调阈值时先记录基线，再用另一批录音复测，避免只适配同一批测试数据。

这是模型评估与阈值校准材料；当前没有用这些录音训练新声学模型，也不采用单张2D手势图片训练骨骼模型。
