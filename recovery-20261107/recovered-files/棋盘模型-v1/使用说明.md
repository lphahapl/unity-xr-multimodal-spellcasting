# 棋盘模型 v1

按已确认的概念图制作：米白格面、彩色边条、深灰底座。所有图案均为真实几何，材质为纯色 PBR，无外部贴图依赖。

## 尺寸

- 单格占地严格为 **1m × 1m**，转角与普通格同尺寸。
- 底座与格面总厚 **0.12m**；边条、箭头、问号和金币略微凸起，最高约 **0.141m**。
- 单格原点在底面中心；按 1 米网格移动即可拼接。
- 整体棋盘 **10m × 10m**，环路 **36 格**，中心面板 **8m × 8m**，可单独删除。
- Blender 为 Z 轴向上；FBX / GLB 导出为 Y 轴向上。源文件以米为单位。

## 文件

| 目录 | 内容 |
| --- | --- |
| Blender | 可编辑的 `ModularBoard_v1.blend`，含完整棋盘、独立模块库和预览灯光相机 |
| FBX | 整体棋盘与 9 种单格，可导入 Unity 等引擎 |
| GLB | 同一组模型，自带 PBR 材质，可用于通用 3D 查看器和 glTF 工具 |
| 预览 | 从实际模型渲染的棋盘与单格图 |
| Unity | Unity 资源与编辑器工具 |

9 种单格：Plain（空白）、Red、Green、Blue、Yellow、Purple（5 种彩色边条）、Start（箭头）、Event（问号）、Coin（金币）。完整棋盘的格子命名带 00–35 的路线编号，每格保留独立层级，图标也可以单独编辑或隐藏。

## Unity 使用

将 `Unity/Assets/ModularBoard` 复制到现有项目的 `Assets`，或导入随附的 `.unitypackage`。

已生成可直接使用的 `Assets/ModularBoard/Prefabs`（10 个预制体）和 `Assets/ModularBoard/Scenes/BoardDemo.unity` 演示场景。Built-in 管线可直接使用；URP / HDRP 项目导入后执行下述菜单更新材质。

若当前工程需要重新生成材质，执行 **Tools → Modular Board → Create Prefabs and Materials**。工具依据当前渲染管线选择 Built-in Standard、URP Lit 或 HDRP Lit，生成 10 个预制体，校验单格与棋盘尺寸，并添加 BoxCollider。

单格碰撞体为 1 × 0.12 × 1 米，放在底面中心上方 0.06 米处；细小浮雕使用统一平面行走碰撞体。棋盘包含 36 个路线碰撞体，中心面板碰撞体可以单独删除。生成的 Prefabs 可以直接拖入场景。更换渲染管线后再次执行菜单即可更新材质；同名生成材质和预制体会被更新。

直接使用 FBX 时，Unity 中保留 Scale Factor = 1、启用 Convert Units。编辑器工具会根据实际包围盒统一到米制尺寸。不要额外把模型放大或缩小 100 倍。GLB 需要支持 glTF 的导入器，Unity 默认使用 FBX 即可。

## Blender 编辑

打开 `Blender/ModularBoard_v1.blend`。`Board_36_Tiles` 是完整棋盘，`Tile_Library_Origin_Centered` 是默认隐藏的独立格子库（模块均在原点，编辑时单独显示所需模块）。`Preview_Only` 与 `Module_Showcase_Preview_Only` 为预览元素，不在导出模型中。

棋盘中同类格子共享网格数据，修改共享网格会同步影响同类格子；需要只改一格时先将其网格设为单用户。

## 验证

`geometry-validation.json` 记录建模尺寸与各单格三角面数；`export-validation.json` 记录 20 个 FBX / GLB 导出文件重新导入后的尺寸、材质与层级检查。`board-layout.json` 保存 36 格的坐标和类型；Unity 坐标字段采用 Blender 到 Y-up 的坐标换算约定，实际业务路径可直接读取场景中各格的 Transform。

已使用本机 Unity 2022.3.62f3c1 完成 FBX 导入、编辑器脚本编译、预制体生成和原生 unitypackage 导出；10 个预制体的实际尺寸、底面原点、材质引用与碰撞体数量全部通过检查，详见 `unity-validation.txt`。实模预览由 Blender 渲染，Unity 验证在无图形界面的批处理模式下完成；URP / HDRP 分支未另建项目验证。

本次交付为静态棋盘和格子美术资源，不含掷骰子、角色移动、买地等游戏逻辑。
