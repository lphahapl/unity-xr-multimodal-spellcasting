# 齿轮工坊——看得见的机械传动

面向机械传动基础认知的离线交互科普网页。解压后直接双击 `dist/index.html`，推荐现代 Chrome 或 Edge。无网络依赖、无安装、无后端，不需要 npm 或编译。

## 完整功能

- 自由搭建：20/30/40/60 齿零件，拖拽吸附、方向键微调、调整齿数、移除、输入/输出选择，最多12轮。
- 实时传动：转速5–60rpm、驱动反向、播放暂停、渐开线齿廓、旋转相位对齐、分度圆与传动路径。
- 教学实验：大小与转速、惰轮作用、奇数闭环冲突，均可直接操作。
- 三项挑战：减速器、同向减速、闭环修复；按实际图结构和运动结果验证，本机保存通过记录。
- 结果解释：有符号传动比、每轮转速与旋向；断开、重叠、闭环冲突分别反馈。
- 文件：JSON设计保存/恢复及严格参数校验；2000×1200 PNG实验图导出。
- 响应式布局和触控拖动，键盘选择/微调，支持系统减少动态效果偏好。

## 技术结构

`dist/core.js` 负责分度圆、20°渐开线采样、空间拓扑、吸附、图遍历求解与设计校验。`dist/app.js` 管理SVG交互、相位动画、实验与挑战、导出及界面反馈。`style.css` 管理响应式布局。浏览器绘图使用原生SVG与Canvas，不依赖第三方库或图像资源。

每个齿轮为图节点，中心距满足半径和的外啮合关系为边。通过主动轮进行BFS求解：ωj = −ωi × zi/zj。若已求解节点在另一条路径上获得矛盾结果，则标记闭环约束冲突。位置重叠或驱动闭环冲突时停止整体动画并解释原因。

## 模型边界

模型只覆盖同模数、固定轴、直齿外啮合的理想运动学，不包含内齿轮、复合轴、行星传动、摩擦、间隙、弹性、强度与负载计算。20°渐开线以离散轮廓作科普示意，不作为制造依据。未连接的齿轮保持静止。学习进度仅存当前浏览器，文件协议下存储行为可能因浏览器而异；设计JSON不依赖浏览器存储。

## 操作

进入自由搭建，点击零件加入。拖动靠近其他齿轮，松开自动吸附。点击选中后，方向键可微调。右侧可改齿数、选择输入/输出轮。切换教学实验或挑战会恢复对应初始布局；导出设计后可随时重新打开。

## 验证

用 Node.js 运行 `node tests/core.test.cjs`。覆盖速比、反向驱动、惰轮、闭环矛盾、重叠、断连、吸附、齿廓有效性、啮合相位及设计文件校验。界面在Chrome/Edge桌面与手机视口中检查；资料截图取自实际运行页面。
