## 在正式二章试玩

从出生点走到石案，右手食指按青铜压面，听到绘符旁白后从工具带取墨规笔。第一笔从左下的“起”到右下的“止”，沿箭头向上、向右、向下画门框。手向自己收回，使笔尖离开纸面约两厘米，再沿亮线画内横。先描内横也可原地补框。沿用停笔约 0.9 秒自动辨符。符成后归笔，用右食指依次指向两岸铜榫，预览出现后握拳，淡金路接岸后走过去。
