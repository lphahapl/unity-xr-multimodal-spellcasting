# 通路符选岸、归笔与实体桥寿命

正式断桥使用 PassageEffect.asset。玩家看见“符成”即可把笔收回，金闪与旁白会接着走。右食指指向两岸后即可放松手指。要取消，先抬手指过岸，随后用空右手张掌，将腕部保持在头部下方至少 60 厘米，持续 1 秒。两个值都可在通路符效果资产调整。

| 状态 | 指偏、放松或短暂失追后 |
| --- | --- |
| 手光与射线 | 持续有手位时，符纹跟随手。指偏时射线可落空，收指隐藏射线。失追时隐藏手光和射线，手位恢复后重现。 |
| 已选第一岸 | 世界里的菱框持续保留。岸位失效后需重选。 |
| 两岸预览 | 指空、调姿、换手形时保留无碰撞轮廓。可指向另一合法岸位换选。重获追踪时若手已握拳须重新伸指或张掌，再握拳。握拳时从当前手位重验实际遮挡、射程和岸位配对。 |
| 成形中的桥 | 握拳后消耗手光，淡金桥独立生长，直到接岸才开放碰撞。 |
| 完成的主桥 | 玩家可走过，已完成教学的存档重载后恢复唯一的可走符桥。未确认的预览只属于当次施法。 |

## 复现依据

用正式二章副本、工具带、实体笔和采样时间戳驱动玩家入口。桌面手部输入使用程序生成的关节轨迹和既有手写样本。所有本轮 Play 运行前已在副本把 Standalone 的 m_InitManagerOnStart 写为 0，进入 Play 后断言活动 XR display 数为 0。没有头显修后真人录像。

- 旧代码在 0.946 分成符后的金闪期间归笔，笔成功回到原槽，选岸未接续。[归笔失败日志](before-early-stow.txt)
- 旧代码在预览后指空 0.569 秒，第一岸和手光均保留，预览关闭。[指偏失败日志](before-ray-miss.txt)
- 新版同一正常入口验证了金闪内归笔、归笔后低手、先选岸再失追、预览后指空、放低和抬手、失追后直接握拳的负例、低位非张掌的负例、低位张掌主动取消，以及从地上再次拾取同一支笔，重画后再次选岸。新出现的实体墙挡住确认，岸位失效会撤掉预览。去掉遮挡并重选后可握拳。成桥后断口中点射线命中桥的碰撞体，玩家走到对岸并读回祭坛存档。[逐段输入时间及结果](route.txt)

## 重放

使用上一级 README 中指定的独立工程和独立存档，从仓库根执行 `python Tools/Validation/Chapter02MainPassage/Retention/prepare.py <副本路径>`，再对同一副本执行 `Unity -batchmode -force-d3d11 -projectPath <副本路径> -executeMethod Chapter02MainPassageReplay.Run`。准备脚本将桌面 XR 关闭写入副本配置，Play 在断言前检查该配置。报告写入副本当次 Logs/MainPassage-日期时间/checks.txt。
