# 工坊炉台旁白联测

源表来自 [V2.4 单向传音](../../../../../docs/architecture/第二章_断衡悬道/08_第二章单向传音台本_V2.4.csv)，本轮配置见 [工坊炉修订台本](../../../../../docs/architecture/第二章_断衡悬道/09_第二章单向传音台本_工坊炉修订.csv)。编号仍为 32 句，既有 32 个 WAV 的哈希均可复核。RT01、RT03、HT02 用同一申屠参考音重录为独立的 `*_WorkshopHearth.wav`。RT02 沿用已录吃饼说明。AB01 和 HT03 沿用已录 A 篮说明，台本同步为上层祭坛清场条件。[字幕、WAV 和 ASR 对照](verified-package.json)

上层祭坛清完三敌后，供给组件把整包与散饼陈列到下层工坊木屋前的明火拱炉。供给组件的 `IsNearHearth` 用玩家脚底与炉面锚点测同层距离，水平最多 3 米，垂直差最多 2 米。站在工坊范围内并靠近炉台才开始 RT01。若已经拿了整包，则从 RT02 继续。RT03 等真实归入中央软袋的回执。主线提示优先，炉边提示使用同一旁白声源。散饼和是否进食各自独立于整包教学。

以 Windows Unity 6000.3.10f1 在禁 XR 的隔离副本测试工坊双包合成场景，场景 SHA-256 `6c30b163aa06ec42bfb14822dc4f26fbe494e6cbb257ed62d6c405077c3bfbb1`。Play 共 112 条 PASS（含 END），Unity 以状态码 0 退出。测试使用正常章节目标与供给组件，玩家脚底移位与对敌伤害由测试脚本输入。先取包分支用进度组件实际收到的拾取状态模拟先后顺序。测试实际调用归袋接口并等待吸附完成。语音通过同一个 NarrationController 的实际声源启动。头显抓取手感与听感另需真机体验。[Play 结果](play.txt) · [实际起播顺序](steps.txt) · [隔离测试入口](HearthNarrationQA.cs)

`HearthNarrationQA.Run` 仅用于隔离副本，该入口依赖既有 `HearthFoodInstaller` 和正式二章资源。合并正式场景由同一名场景维护者负责。
