# 第二幕单向传音验收

语音源为 Gemini 审阅后落盘的 [V2.4 台本](../../../../docs/architecture/第二章_断衡悬道/08_第二章单向传音台本_V2.4.csv)。Chrome 远端调试确认了本机声音工作台。32 句均采用首章审核版「旁白_常态」参考音和工作台 Qwen3 0.6B。前段通过工作台服务生成，其余使用同一工作台的离线推理模块与 CUDA Graphs，长句在标点间分段合成。整句资源为 48 kHz、PCM 16 位、单声道，总时长约 405.62 秒。[音频与转写清单](manifest.json)

AL01 按现有祭坛守敌进入警戒后可受击的规则配音。AB01 和 HT03 去掉了已经拿到干粮的前提，玩家可直接尝试乘 A 篮。源表保留，清单的 `text` 与场景实际台词一致。

[正式二章场景](../../../../Assets/Scene/Chapter02_SuspendedPath.unity) 使用一套播放队列和申屠字幕，按章节进度读取交互事实。进度继续由章节和交互组件管理。短促提示在相关目标连续 18 秒没有进展、声源空闲时进入队列。炉台的 RT01、RT02、RT03、HT02 读取 `IHearthRationNarrationProgress` 的整包提供、拾取和中央袋口收纳状态，散饼由吃食会话独立跟踪。炉台物件尚待该会话确认摆点并发布，正式场景目前不会触发这四句，登 A 篮可直接推进。

Unity 6000.3.10f1 在关闭 XR 的 Windows 工程副本运行。实际场景从新局自动播放 EN01，桌面脚底到达真实石案区域后推进，随后用画板成功回调模拟验收 BR01→BR02。32 条序列化台词逐条走资源加载与实际声源起播检查。独立启动用已有主榫坐实存档恢复 B 篮段，实际播 BDN01，检查了入口、A 篮和谷底的旧提示未抢播。Quest 中的音量和临场听感还需实测。机器转写用于核对缺句和异常，考工术语的听感另行复核。[新局与资源测试](play.txt) · [B 篮读档](cold-b.txt) · [正式资产读回](publish.json)
