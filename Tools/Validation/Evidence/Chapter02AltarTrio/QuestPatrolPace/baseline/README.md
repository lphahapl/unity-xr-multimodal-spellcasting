# 修复前的祭坛巡逻

Unity 6000.3.10f1 的隔离工程载入正式章节快照 `CE338BB5`。玩家位于首次接敌线外两米，沿祭坛方向看了八秒。原摄像机画面在 `preview-camera.png`。每名守敌在 240 帧内均可见。普通近战与背石工奴的最大水平位移均为 0.000 米，掷火也停在原地。角色线外拒绝受击，玩家健康值未变。两条最低巡逻位移断言失败，因此进程返回 1。

跨线后三个控制器、三份租约和镇石刚体沿用预展示实例。工奴受非致命一击后实际撤离 1.84 米，先击杀工奴会掉落原石。后续击杀近战与掷火，清场事件计数依次为 0、0、1。

表中高度均以角色脚下实际物理地面为零。头骨高度取骨骼中心。脚底取至少一半权重由脚或脚趾层级控制的最低蒙皮顶点。工奴身上的镇石有八个独立网格，单列。普通近战与掷火可见身体各来自一个整体蒙皮。移动或攻击期间手臂、武器和站姿变化会改变整体顶点的最高点。

`frames.csv` 是逐帧世界坐标，`metrics.json` 汇总各时段的最低、中位和最高值，`assertions.txt` 留存场景实例、校准误差和全部断言。仿真眼高为 1.1176 米。本次调用了原绘桥目标的完成方法，以进入古桥修复后的祭坛测例。角色导航、攻击与 XR 玩家组件均使用场景原件。基线对应探针保存在 `probes/`。
