### 祭坛手感与关卡边界

实测工奴向外撤退时，原镇石会落到篮外较远一侧。玩家站在篮内偏后位置、持续瞄石心，可能先碰到射程极限或尚在播放倒地动作的工奴身体。向篮内前沿迈一步，瞄露出的石面再回拉，可以用原千钧符把同一件镇石拉入原槽。观察记录保留了首次瞄准被身体受击区遮挡的距离和石块轨迹。射程维持 8 米。

A 篮接线包含一次镇石就位事件。基线中该事件的持久监听数为 0，吊篮升降和全章通关仍需后续机关接线。测试使用桌面模拟的玩家位置、笔尖与右手输入，Quest 真机待验。主榫本体沿用白盒，外观沿原审稿流程定稿。
