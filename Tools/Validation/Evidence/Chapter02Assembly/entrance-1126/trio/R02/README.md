# 第二章 R02 上背搬运复核

独立 Unity 6000.3.10f1 GPU Play，使用原章节的 XR 玩家相机和模拟手部输入。R02 模型、动画、姿势、工奴脚本和镇石资产来自 D 盘正式工程。两次 Unity 进程退出码均为 0。

选取的 A 篮局部修订场景 SHA-256 为 `1be75566173fe09ec6efd8ff2bee7f00bcecc8aec5c652f3496469fbd8ef0353`。第一次复制时正式场景磁盘 SHA-256 为 `c56d7380bef12e6104f59a28f1926009e74b425db6c9c62621ee414c142022d2`。

全新存档按实际入口步行到断桥，用实笔绘方直之矩后步行进入祭坛。三敌与镇石贯穿桥头与开战；首遇、原剪辑和实石在玩家镜头中均已确认。

高度以较低踝骨为参照，覆盖文件中的 48 个非重复相位；末尾循环重复点仅存档。当前工奴实际动作中肩高为 1.0825–1.1078 米，髋高为 0.6962–0.7182 米。记录到导航巡逻峰值 0.5426 米/秒、撤离峰值 0.7228 米/秒，0.9001 秒撤离窗口内根位移 0.6142 米。

另一轮从实际修桥存档出发，击破三敌。死亡前后世界位置相同，原石与刚体编号依次为 -6258、-6254。通过自由板两次书写千钧，原石触发一次入槽并启动 A 篮下降。普通步行下篮由场景装配组另验。
