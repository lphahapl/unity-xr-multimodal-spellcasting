## 在独立副本复跑

准备相同版本的独立、已关闭的工程副本。在副本的 `Assets/XR/XRGeneralSettingsPerBuildTarget.asset` 内，将各平台的 `m_InitManagerOnStart` 设为 `0`、`m_Loaders` 设为 `[]`，并保持自动加载及自动运行关闭。运行器会核对设置，把两个测试脚本放入副本的 Editor 目录，并用单独的临时存档启动桌面 Play。报告目录使用尚未创建的路径。

```powershell
& .\Tools\Validation\Chapter02WalkContact\run.ps1 -Replica 'D:\Temp\Ch02WalkContact-1126\Project' -Report 'D:\Temp\WalkContact-Retest'
```

退出码 0 表示全部断言通过。在报告目录查看 `results.txt` 和 `frames.tsv`。[复跑脚本](run.ps1)
